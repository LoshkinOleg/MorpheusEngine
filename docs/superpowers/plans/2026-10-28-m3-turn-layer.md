# Milestone 3: The Turn Layer - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the engine playable end to end. A player input becomes a committed turn:
1. retrieve memory;
2. (assisted mode) look things up;
3. resolve with a schema-generated grammar;
4. apply the changes with engine dice;
5. narrate;
6. commit.

Between turns, the engine embeds folded history and folds or condenses memory. A worker thread drives all of it. Replay tests pin it down, and a console tool lets the owner play before the ImGui app exists (M4).

**Architecture:**
- **New module `morpheus_turn`** (`src/turn`), over `core`, `store`, `inference` and `context`. It has no llama.cpp, so the `tests` and `asan` presets build and test all of it with fake backends.
  - `ResolveGrammar`: GBNF from the world and the live state.
  - `Resolve`: reads the output, rolls, applies, writes the narrate message.
  - `EngineText`: the L0 rules and the instructions.
  - `Retrieval`: the memory index.
  - `Folding`: summary calls.
  - `Session`: one open run and its turn loop.
  - `Worker`: the thread and its command/event queues.
  - `Replay`: recording and fixtures.
- **Console tool:** `tools/play` (`morpheus_play`, `dev` preset) plays a world in the terminal through the `Worker`.
- **Spec:** `docs/superpowers/specs/2026-10-27-morpheus-cpp-architecture-design.md`.

**Tech Stack:** C++20 with MSVC (VS 2022) and CMake 3.25+. The dependencies are as in milestone 2: llama.cpp `960d628f46d17ea9c10aa944b061b2341afeb3b5` with Vulkan, nlohmann/json, SQLite, and Catch2. No new dependencies.

**Decisions for this milestone (made with the product owner):**
- **Over-removal is rejected.** Removing more of a counted item than is held is rejected with "only N 'item' held". Reaching exactly 0 removes the item, with the note "none left". This replaces the clamp-and-remove behavior and the nested "(removed (count reached 0))" note.
- **Regenerate keeps the dice.** `CheckSeed(runSeed, turn, checkIndex)` is unchanged, so a regenerated turn rolls the same faces. Text sampling varies through `SamplingSeed(runSeed, turn, kind, attempt)`. `TurnRecord::attempt` counts regenerations and is stored with the turn.

**Technical decisions (from the M2 carry-overs):**
- **Grammars are generated by the engine as GBNF text** (`turn/ResolveGrammar`), not through llama.cpp's `common` json-schema-to-grammar:
  - The grammar enumerates every live entity's fields with their value types, and new-entity shapes per creatable type. As a JSON schema that would be a large `oneOf` tree anyway.
  - `common` is llama.cpp's helper library. Linking it would put llama.cpp into a module that must build under `tests`.
  - Generated text is unit-testable without a model. A `[llama]` test proves llama.cpp compiles the grammar.
- **L0 is world-independent.** `ENGINE_RULES` describes the turn and the JSON shape in general terms. The world's stats, difficulties and entity types are in L1, rendered by `context::RenderWorldReference`.
- **Memory calls share the stable prefix.** A fold call's prompt is the system message, then the oldest turns, then an instruction. A condense call's is the system message, then an instruction. Both are prefixes, or near-prefixes, of the resolve prompt, so no `SaveState`/`RestoreState` is needed around them in M3.
- **Notes are retrieved, not pinned.** Assisted-mode notes are embedded (`EmbeddingKind::Note`) and come back through retrieval (T2). Putting them in L2 would invalidate the cached transcript on every note.
- **Retrieval budget:** a new `budget.retrieval_cap` setting (1..`tail_allowance`) caps T2 tokens.
  - Hits are taken by score, at most `RETRIEVAL_MAX_HITS`.
  - Lore subjects named in the input get `NAME_BOOST`.
  - Turns still in L3 are never retrieved.
- **Embedding identity covers the prefix.** A stored vector's content hash is FNV-1a over the document prefix and the embedded text. A changed prefix, edited text or other model re-embeds.
- **`contextOverflow` is the authoritative fit check.** The turn's fit loop, in order:
  1. sheds retrieval hits while the tail is over budget;
  2. condenses an over-cap summary;
  3. folds the oldest half of the transcript while the transcript or the whole prompt is over;
  4. sheds hits as a last resort;
  5. otherwise reports `TurnError`.
- **`memory_mode`** is an optional `settings.json` key that overrides the world's default.
- **Opening a run** checks that it belongs to the world and that its latest state still validates against the world's schema (a `DataError` otherwise). Edited world files (another content hash) open with `WorldChanged()` true and re-embed the lore that changed.
- **Cancel discards the turn.** Nothing is committed. A cancelled regenerate puts the original turn back.
- **Unreadable resolve output is a model mistake.** That covers output cut off at `resolve_max_tokens`, or JSON of the wrong shape. The turn goes on with nothing proposed, the resolution record says so, and the narrate call still runs.
- **Player input** is stripped of control characters (except newline and tab). The backend tokenizes message contents without special-token parsing, so text like `<|im_end|>` stays plain text.
- **Dropped from the carry-over list:** a `RejectedChange` index field. The raw JSON already identifies the change.

**Roadmap:** M4 is the ImGui app over `turn::Worker`, and its inspectors read `TurnCompleted::assembly` and the record's telemetry.

## Global Constraints

- **Toolchain:** C++20 (`cxx_std_20`), MSVC through the `Visual Studio 17 2022` generator, x64, Windows 10. CMake >= 3.25.
- **Dependencies:** none added. llama.cpp stays at `960d628f46d17ea9c10aa944b061b2341afeb3b5`.
- **Flags:** every MorpheusEngine target calls `morpheus_target_defaults()` (`/W4 /WX /permissive- /Zc:preprocessor /utf-8`). Never apply these to fetched dependencies.
- **Namespaces and targets:**
  - The namespaces are `morpheus::core`, `store`, `inference`, `context`, `llama` and `turn`.
  - Targets are `morpheus_<module>`, and includes are written as `"module/File.h"`.

  - Engine bugs throw `core::ContractError` (via `MORPHEUS_REQUIRE`).

  - Model, runtime and llama.cpp failures throw `inference::InferenceError`.
  - A turn that cannot run as asked throws `turn::TurnError`, with a message for the player.
  - Model mistakes are values, never exceptions. These are invalid changes, unknown stats, unreadable output, and lookups that do not fit.

```cpp
#pragma once

#include <cstddef>
#include <filesystem>
#include <string>
#include <string_view>

#include <nlohmann/json.hpp>

namespace morpheus::core {

// A path as UTF-8 with '/' separators, for messages and for C APIs that take UTF-8. path::string() and
// generic_string() convert through the ANSI code page on Windows, which mangles non-ASCII folder names.
std::string PathText(const std::filesystem::path& path);

// Longest JSON text ShortJson keeps; longer text is cut and ends with "...".
constexpr std::size_t SHORT_JSON_CHARS = 80;

// `value` as compact ASCII JSON (non-ASCII is escaped, so a cut never splits a character), cut to SHORT_JSON_CHARS.
// For rejection reasons, which reach the narrate prompt: a huge proposed value must not flood it.
std::string ShortJson(const nlohmann::json& value);

// The longest prefix of `text` of at most maxBytes bytes that ends on a UTF-8 character boundary.
std::string CutUtf8(std::string_view text, std::size_t maxBytes);

// `text` without leading and trailing spaces, tabs, carriage returns and newlines.
std::string Trim(std::string_view text);

} // namespace morpheus::core
```

Create `src/core/Text.cpp`:

```cpp
#include "core/Text.h"

namespace morpheus::core {

std::string PathText(const std::filesystem::path& path)
{
    const std::u8string text = path.generic_u8string();
    return std::string(reinterpret_cast<const char*>(text.data()), text.size());
}

std::string ShortJson(const nlohmann::json& value)
{
    std::string text = value.dump(-1, ' ', true);
    if (text.size() > SHORT_JSON_CHARS) {
        text.resize(SHORT_JSON_CHARS);
        text += "...";
    }
    return text;
}

std::string CutUtf8(std::string_view text, std::size_t maxBytes)
{
    if (text.size() <= maxBytes) {
        return std::string(text);
    }
    // Back off while the first byte left out is a continuation byte (10xxxxxx): the cut is inside a character.
    std::size_t length = maxBytes;
    while (length > 0 && (static_cast<unsigned char>(text[length]) & 0xC0) == 0x80) {
        --length;
    }
    return std::string(text.substr(0, length));
}

std::string Trim(std::string_view text)
{
    constexpr std::string_view WHITESPACE = " \t\r\n";
    const std::size_t first = text.find_first_not_of(WHITESPACE);
    if (first == std::string_view::npos) {
        return {};
    }
    const std::size_t last = text.find_last_not_of(WHITESPACE);
    return std::string(text.substr(first, last - first + 1));
}

} // namespace morpheus::core
```

```cpp
std::uint32_t SamplingSeed(std::uint64_t runSeed, int turn, CallKind kind, int attempt)
{
    MORPHEUS_REQUIRE(turn >= 0 && attempt >= 0 && attempt < (1 << 24),
                     "SamplingSeed: turn must be >= 0 and attempt in 0..2^24-1");
    const std::uint64_t base = SplitMix64(runSeed ^ SAMPLING_SALT).Next();
    // Turn in the high half; kind and attempt in the low half (attempt < 2^24 leaves the kind bits alone).
    SplitMix64 mixer(base ^ ((static_cast<std::uint64_t>(turn) << 32) | (static_cast<std::uint64_t>(kind) << 24) |
                             static_cast<std::uint64_t>(attempt)));
    return static_cast<std::uint32_t>(mixer.Next() >> 32);
}
```

```cpp
// The log sink and the level of the line being logged, shared by every thread llama.cpp logs from.
struct LogRoute {
    std::mutex mutex = {};
    LogSink sink = {};
    LogLevel lastLevel = LogLevel::Info; // Continuation pieces (GGML_LOG_LEVEL_CONT) inherit it.
};

LogRoute& Route()
{
    static LogRoute route;
    return route;
}

// llama.cpp and ggml log through one process-wide callback; it forwards to the sink.
void LogCallback(ggml_log_level level, const char* pText, void* /*pUserData*/)
{
    LogRoute& route = Route();
    std::scoped_lock lock(route.mutex);
    switch (level) {
    case GGML_LOG_LEVEL_DEBUG:
        route.lastLevel = LogLevel::Debug;
        break;
    case GGML_LOG_LEVEL_WARN:
        route.lastLevel = LogLevel::Warn;
        break;
    case GGML_LOG_LEVEL_ERROR:
        route.lastLevel = LogLevel::Error;
        break;
    case GGML_LOG_LEVEL_CONT:
        break; // Continues the previous line at its level.
    default:
        route.lastLevel = LogLevel::Info; // INFO and NONE.
        break;
    }
    const std::string_view text = pText != nullptr ? pText : "";
    if (route.sink) {
        route.sink(route.lastLevel, text);
    } else if (route.lastLevel == LogLevel::Warn || route.lastLevel == LogLevel::Error) {
        std::fwrite(text.data(), 1, text.size(), stderr);
    }
}
```

```cpp
    // the template is rendered with a marker in place of each content, and the pieces are tokenized apart:
    // template text with parse_special (its control tokens are real), contents without it.
    inference::Prompt marked = prompt;
    for (inference::Message& message : marked.messages) {
        if (message.content.find(CONTENT_MARKER) != std::string::npos) {
            throw InferenceError("a message contains the reserved character U+001E");
        }
        message.content = std::string(1, CONTENT_MARKER);

    const std::string rendered = RenderPrompt(marked);

    const llama_vocab* pVocab = llama_model_get_vocab(_pChatModel.get());
    // BOS is added when the model expects one; if the template already wrote it, the duplicate is dropped below.
    const bool addBos = llama_vocab_get_add_bos(pVocab);
    std::vector<std::int32_t> tokens;
    auto append = [&tokens](const std::vector<std::int32_t>& more) { tokens.insert(tokens.end(), more.begin(), more.end()); };
    std::size_t start = 0;

    for (;;) {

        const std::string_view templateText =

        if (!prompt.messages[message].content.empty()) {
```

```cpp
std::string RenderWorldReference(const core::World& world)
{
    std::vector<std::pair<std::string, int>> difficulties(world.difficulties.begin(), world.difficulties.end());
    std::stable_sort(difficulties.begin(), difficulties.end(),
                     [](const auto& a, const auto& b) { return a.second < b.second; });

    std::string text = "# Game reference\n";
    text += std::format("Checks roll {}d{}{} and succeed at or above the difficulty:", world.dice.count,
                        world.dice.sides, world.dice.addStat ? "+stat" : "");
    for (std::size_t i = 0; i < difficulties.size(); ++i) {
        text += std::format("{} {} {}", i == 0 ? "" : ",", difficulties[i].first, difficulties[i].second);
    }
    text += ".\n";

    text += std::format("Stats (int fields of {}):", world.checkEntity);
    for (std::size_t i = 0; i < world.stats.size(); ++i) {
        text += (i == 0 ? " " : ", ") + world.stats[i];
    }
    text += ".\nEntity types:\n";

    for (const auto& [typeName, type] : world.schema.EntityTypes()) {
        text += std::format("- {}{}:", typeName, type.creatable ? " (creatable)" : "");
        bool first = true;
        for (const auto& [fieldName, def] : type.fields) {
            text += first ? " " : ", ";
            first = false;
            switch (def.type) {
            case core::FieldType::Int:
                text += std::format("{} (int {}..{})", fieldName, def.min, def.max);
                break;
            case core::FieldType::Enum: {
                std::string values;
                for (std::size_t i = 0; i < def.values.size(); ++i) {
                    values += (i == 0 ? "" : ", ") + def.values[i];

            case core::FieldType::String:
            case core::FieldType::List:
            case core::FieldType::Counter:
                text += std::format("{} ({})", fieldName, core::FieldTypeName(def.type));
                break;
            }
        }
        text += '\n';
    }
    return text;
}
```

```cpp
constexpr int MAX_CHECKS = 3;

// in this order:
//   {"intent": str, "checks": [check], "changes": [change]}, plus "notes": [str] in assisted mode
//   check:  {"stat", "difficulty", "stakes": str, "on_success": [change], "on_failure": [change]}
//   change: {"op", "path", "value" (absent for a counter item remove), "reason": str}
```

```cpp
#include "turn/ResolveGrammar.h"

#include <format>
#include <map>
#include <string_view>
#include <vector>

#include "core/Errors.h"

namespace morpheus::turn {

namespace {

// Shared terminals. Strings are bounded JSON strings; integers have at most 9 digits, so they always fit an int.
// Placeholders: {0} short text, {1} long text, {2} item name, {3} new id length, {4} extra list items.
constexpr std::string_view TERMINALS = R"gbnf(char ::= [^"\\\x7F\x00-\x1F] | "\\" (["\\/bfnrt] | "u" [0-9a-fA-F]{{4}})
short-text ::= "\"" char{{0,{0}}} "\""
long-text ::= "\"" char{{0,{1}}} "\""
int ::= "0" | "-"? [1-9] [0-9]{{0,8}}
nonzero-int ::= "-"? [1-9] [0-9]{{0,8}}
pos-int ::= [1-9] [0-9]{{0,8}}
item ::= [a-z0-9_]{{1,{2}}}
new-id ::= "\"" [a-z0-9_:]{{1,{3}}} "\""
text-list ::= "[]" | "[" short-text ("," short-text){{0,{4}}} "]"
counter-value ::= "{{}}" | "{{\"" item "\":" pos-int (",\"" item "\":" pos-int){{0,{4}}} "}}"
reason ::= ",\"reason\":" short-text "}}"
)gbnf";

std::string Terminals()
{
    return std::format(TERMINALS, SHORT_TEXT_CHARS, LONG_TEXT_CHARS, MAX_ITEM_CHARS, MAX_NEW_ID_CHARS,
                       MAX_LIST_ITEMS - 1);
}

// A GBNF string literal that matches `text` exactly.
std::string Literal(std::string_view text)
{
    std::string result = "\"";
    for (const char c : text) {
        if (c == '"' || c == '\\') {
            result += '\\';
        }
        result += c;
    }
    return result + "\"";
}

// Alternatives matching each value as a JSON string.
std::string Alternatives(const std::vector<std::string>& values)
{
    MORPHEUS_REQUIRE(!values.empty(), "Alternatives: needs at least one value");
    std::string result;
    for (const std::string& value : values) {
        result += (result.empty() ? "" : " | ") + Literal(nlohmann::json(value).dump());
    }
    return result;
}

// A JSON array of 0 to maxItems `element`s.
std::string ListOf(std::string_view element, int maxItems)
{
    MORPHEUS_REQUIRE(maxItems >= 2, "ListOf: maxItems must be at least 2");
    return std::format(R"("[]" | "[" {0} ("," {0}){{0,{1}}} "]")", element, maxItems - 1);
}

} // namespace

std::string BuildResolveGrammar(const core::World& world, const nlohmann::json& state, core::MemoryMode mode)
{
    MORPHEUS_REQUIRE(state.is_object(), "BuildResolveGrammar: state must be validated state");
    const bool assisted = mode == core::MemoryMode::Assisted;

    std::string rules;                           // change-N and enum-N definitions.
    std::vector<std::string> changes;            // Names of the change-N rules.
    std::map<std::string, std::string> enums;    // "type.field" -> enum-N rule name.

    // The value rule for a field; an enum gets its own rule the first time it is used.
    auto valueRule = [&](const std::string& typeName, const std::string& fieldName, const core::FieldDef& def) {
        switch (def.type) {
        case core::FieldType::Int:
            return std::string("int");
        case core::FieldType::String:
            return std::string("short-text");
        case core::FieldType::List:
            return std::string("text-list");
        case core::FieldType::Counter:
            return std::string("counter-value");
        case core::FieldType::Enum: {
            auto it = enums.find(typeName + "." + fieldName);
            if (it == enums.end()) {
                const std::string name = std::format("enum-{}", enums.size());
                rules += name + " ::= " + Alternatives(def.values) + "\n";
                it = enums.emplace(typeName + "." + fieldName, name).first;
            }
            return it->second;
        }
        }
        throw core::ContractError("BuildResolveGrammar: unhandled FieldType");
    };
    auto addChange = [&](const std::string& body) {
        changes.push_back(std::format("change-{}", changes.size()));
        rules += changes.back() + " ::= " + body + "\n";
    };

    // Changes to the fields of every entity that exists now.
    for (auto entity = state.begin(); entity != state.end(); ++entity) {
        const core::EntityTypeDef* pType = world.schema.FindEntityType(entity.value().at("type").get<std::string>());
        MORPHEUS_REQUIRE(pType != nullptr, "BuildResolveGrammar: state has an unknown entity type");
        for (const auto& [fieldName, def] : pType->fields) {
            const std::string path = entity.key() + "." + fieldName;
            const std::string pathValue = Literal(",\"path\":\"" + path + "\",\"value\":");
            switch (def.type) {
            case core::FieldType::Int:
                addChange(Literal("{\"op\":") + " (" + Literal("\"set\"") + " | " + Literal("\"add\"") + ") " +
                          pathValue + " int reason");
                break;
            case core::FieldType::Enum:
                addChange(Literal("{\"op\":\"set\"") + " " + pathValue + " " +
                          valueRule(entity.value().at("type").get<std::string>(), fieldName, def) + " reason");
                break;
            case core::FieldType::String:
                addChange(Literal("{\"op\":\"set\"") + " " + pathValue + " short-text reason");
                break;
            case core::FieldType::List:
                addChange(Literal("{\"op\":") + " (" + Literal("\"add\"") + " | " + Literal("\"remove\"") + ") " +
                          pathValue + " short-text reason");
                break;
            case core::FieldType::Counter:
                addChange("(" + Literal("{\"op\":\"add\",\"path\":\"" + path + ".") + " item " +
                          Literal("\",\"value\":") + " nonzero-int | " +
                          Literal("{\"op\":\"remove\",\"path\":\"" + path + ".") + " item " + Literal("\"") +
                          ") reason");
                break;
            }
        }
    }

    // New entities of creatable types, every field given.
    for (const auto& [typeName, type] : world.schema.EntityTypes()) {
        if (!type.creatable) {
            continue;
        }
        std::string fields;
        for (const auto& [fieldName, def] : type.fields) {
            fields += " " + Literal((fields.empty() ? "\"" : ",\"") + fieldName + "\":") + " " +
                      valueRule(typeName, fieldName, def);
        }
        addChange(Literal("{\"op\":\"create\",\"path\":") + " new-id " +
                  Literal(",\"value\":{\"type\":\"" + typeName + "\",\"fields\":{") + fields + " " + Literal("}}") +
                  " reason");
    }
    MORPHEUS_REQUIRE(!changes.empty(), "BuildResolveGrammar: the state has no fields to change");

    std::vector<std::string> difficulties;
    for (const auto& [name, target] : world.difficulties) {
        difficulties.push_back(name);
    }

    std::string grammar = "root ::= " + Literal("{\"intent\":") + " short-text " + Literal(",\"checks\":") +
                          " checks " + Literal(",\"changes\":") + " changes " +
                          (assisted ? Literal(",\"notes\":") + " notes " : "") + Literal("}") + "\n";
    grammar += "checks ::= " + ListOf("check", MAX_CHECKS) + "\n";
    grammar += "check ::= " + Literal("{\"stat\":") + " stat " + Literal(",\"difficulty\":") + " difficulty " +
               Literal(",\"stakes\":") + " short-text " + Literal(",\"on_success\":") + " branch " +
               Literal(",\"on_failure\":") + " branch " + Literal("}") + "\n";
    grammar += "branch ::= " + ListOf("change", MAX_BRANCH_CHANGES) + "\n";
    grammar += "changes ::= " + ListOf("change", MAX_CHANGES) + "\n";
    if (assisted) {
        grammar += "notes ::= " + ListOf("long-text", MAX_NOTES) + "\n";
    }
    grammar += "stat ::= " + Alternatives(world.stats) + "\n";
    grammar += "difficulty ::= " + Alternatives(difficulties) + "\n";
    std::string changeAlternatives;
    for (const std::string& name : changes) {
        changeAlternatives += (changeAlternatives.empty() ? "" : " | ") + name;
    }
    grammar += "change ::= " + changeAlternatives + "\n";
    return grammar + rules + Terminals();
}

std::string BuildLookupGrammar()
{
    std::string grammar = "root ::= " + Literal("{\"lookups\":") + " lookups " + Literal("}") + "\n";
    grammar += "lookups ::= " + ListOf("lookup", MAX_LOOKUPS) + "\n";
    grammar += "lookup ::= " + Literal("{\"source\":") + " (" + Literal("\"lore\"") + " | " +
               Literal("\"history\"") + " | " + Literal("\"notes\"") + ") " + Literal(",\"query\":") +
               " short-text " + Literal("}") + "\n";
    return grammar + Terminals();
}

} // namespace morpheus::turn
```

```cpp
    std::vector<ProposedCheck> checks = {};

    nlohmann::json state = nullptr; // State after the applied changes.
    std::vector<core::CheckOutcome> checks = {};
    std::vector<core::AppliedChange> applied = {};
    std::vector<core::RejectedChange> rejected = {};
};

// Rolls the i-th proposed check with CheckSeed(runSeed, turn, i), so a regenerated turn keeps its rolls. Then
// applies the unconditional changes, followed by each rolled check's success or failure changes in check order.

//   <NARRATE_INSTRUCTION>
```

```cpp
#include "turn/Resolve.h"

#include <algorithm>
#include <cstddef>
#include <format>

#include "context/Transcript.h"
#include "core/Dice.h"
#include "core/Errors.h"
#include "turn/EngineText.h"

namespace morpheus::turn {

ResolveProposal ParseResolveOutput(std::string_view text)
{
    auto failed = [](std::string why) {
        ResolveProposal proposal;
        proposal.error = std::move(why);
        return proposal;
    };
    const nlohmann::json json = nlohmann::json::parse(text, nullptr, false);
    if (json.is_discarded()) {
        return failed("the output is not complete JSON; it may have hit resolve_max_tokens");
    }
    if (!json.is_object() || !json.contains("intent") || !json.at("intent").is_string()) {
        return failed("'intent' must be a string");
    }
    if (!json.contains("checks") || !json.at("checks").is_array()) {
        return failed("'checks' must be an array");
    }
    if (!json.contains("changes") || !json.at("changes").is_array()) {
        return failed("'changes' must be an array");
    }

    ResolveProposal proposal;
    proposal.intent = json.at("intent").get<std::string>();
    proposal.changes = json.at("changes");
    const nlohmann::json& checks = json.at("checks");
    for (std::size_t i = 0; i < checks.size(); ++i) {
        const nlohmann::json& check = checks[i];
        auto has = [&check](const char* key, bool string) {
            return check.contains(key) && (string ? check.at(key).is_string() : check.at(key).is_array());
        };
        if (!check.is_object() || !has("stat", true) || !has("difficulty", true) || !has("stakes", true) ||
            !has("on_success", false) || !has("on_failure", false)) {
            return failed(std::format("check {} needs strings 'stat', 'difficulty' and 'stakes' and arrays "
                                      "'on_success' and 'on_failure'",
                                      i + 1));
        }
        proposal.checks.push_back({check.at("stat").get<std::string>(), check.at("difficulty").get<std::string>(),
                                   check.at("stakes").get<std::string>(), check.at("on_success"),
                                   check.at("on_failure")});
    }
    if (json.contains("notes")) {
        const nlohmann::json& notes = json.at("notes");
        if (!notes.is_array() || !std::all_of(notes.begin(), notes.end(), [](const auto& n) { return n.is_string(); })) {
            return failed("'notes' must be an array of strings");
        }
        for (const nlohmann::json& note : notes) {
            proposal.notes.push_back(note.get<std::string>());
        }
    }
    return proposal;
}

Resolution ApplyProposal(const core::World& world, const nlohmann::json& state, const ResolveProposal& proposal,
                         std::uint64_t runSeed, int turn)
{
    MORPHEUS_REQUIRE(state.contains(world.checkEntity), "ApplyProposal: the state has no check entity");
    const nlohmann::json& statFields = state.at(world.checkEntity).at("fields");

    Resolution resolution;
    nlohmann::json changes = proposal.changes;
    std::vector<core::RejectedChange> badChecks;
    for (std::size_t i = 0; i < proposal.checks.size(); ++i) {
        const ProposedCheck& check = proposal.checks[i];
        const bool knownStat = std::find(world.stats.begin(), world.stats.end(), check.stat) != world.stats.end();
        const auto difficulty = world.difficulties.find(check.difficulty);
        if (!knownStat || difficulty == world.difficulties.end()) {
            const nlohmann::json raw = {{"stat", check.stat}, {"difficulty", check.difficulty}, {"stakes", check.stakes}};
            badChecks.push_back({raw, !knownStat ? std::format("unknown stat '{}'", check.stat)
                                                 : std::format("unknown difficulty '{}'", check.difficulty)});
            continue;
        }
        // The seed index is the check's position in the proposal, so one rejected check never shifts the others.
        core::CheckOutcome outcome = {check.stat, check.difficulty, check.stakes,
                                      core::RollCheck(world.dice, statFields.at(check.stat).get<int>(),
                                                      difficulty->second,
                                                      core::CheckSeed(runSeed, turn, static_cast<int>(i)))};
        const nlohmann::json& branch = outcome.result.success ? check.onSuccess : check.onFailure;
        changes.insert(changes.end(), branch.begin(), branch.end());
        resolution.checks.push_back(std::move(outcome));
    }

    core::ApplyResult applied = core::ApplyChanges(world.schema, state, changes);
    resolution.state = std::move(applied.state);
    resolution.applied = std::move(applied.applied);
    resolution.rejected = std::move(badChecks);
    resolution.rejected.insert(resolution.rejected.end(), applied.rejected.begin(), applied.rejected.end());
    return resolution;
}

std::string RenderNarrateMessage(const ResolveProposal& proposal, const Resolution& resolution, int allowance,
                                 inference::LlmBackend& backend)
{
    const std::string task = "\n# Task\n" + std::string(NARRATE_INSTRUCTION);
    if (!proposal.error.empty()) {
        return std::format("# Resolution\nThe action could not be resolved ({}). Nothing changed.\n{}", proposal.error,
                           task);
    }

    std::string checks;
    for (const core::CheckOutcome& check : resolution.checks) {
        std::string rolls;
        for (const int roll : check.result.rolls) {
            rolls += (rolls.empty() ? "" : " + ") + std::to_string(roll);
        }
        const std::string stat = check.result.statValue != 0 ? std::format(" {:+}", check.result.statValue) : "";
        checks += std::format("Check: {} vs {} ({}): rolled {}{} = {}, {}. Stakes: {}\n", check.stat, check.difficulty,
                              check.result.target, rolls, stat, check.result.total,
                              check.result.success ? "success" : "failure", check.stakes);
    }
    std::vector<std::string> applied;
    for (const core::AppliedChange& change : resolution.applied) {
        applied.push_back(context::RenderChangePart(change));
    }
    std::vector<std::string> rejected;
    for (const core::RejectedChange& change : resolution.rejected) {
        const nlohmann::json& raw = change.raw;
        const bool named = raw.is_object() && raw.contains("op") && raw.at("op").is_string() && raw.contains("path") &&
                           raw.at("path").is_string();
        rejected.push_back(named ? std::format("{} {} ({})", raw.at("op").get<std::string>(),
                                               raw.at("path").get<std::string>(), change.reason)
                                 : change.reason);
    }
    auto join = [](const std::vector<std::string>& parts, std::size_t count) {
        std::string text;
        for (std::size_t i = 0; i < count; ++i) {
            text += (i == 0 ? "" : "; ") + parts[i];
        }
        return text;
    };

    // Render, then shed detail until the message fits the narrate allowance: the rejected changes first, then
    // applied changes from the end.
    bool showRejected = !rejected.empty();
    std::size_t appliedShown = applied.size();
    for (;;) {
        std::string text = "# Resolution\nIntent: " + proposal.intent + "\n" + checks;
        if (applied.empty()) {
            text += "Applied: none\n";
        } else {
            text += "Applied: " + join(applied, appliedShown);
            if (appliedShown < applied.size()) {
                text += std::format("{}and {} more", appliedShown == 0 ? "" : "; ", applied.size() - appliedShown);
            }
            text += "\n";
        }
        if (showRejected) {
            text += "Rejected: " + join(rejected, rejected.size()) + "\n";
        }
        text += task;
        if (backend.CountTokens(text) <= allowance) {
            return text;
        }
        if (showRejected) {
            showRejected = false;
        } else if (appliedShown > 0) {
            --appliedShown;
        } else {
            throw core::DataError(std::format("narrate_allowance {} is too small for the resolution record ({} tokens)",
                                              allowance, backend.CountTokens(text)));
        }
    }
}

std::vector<Lookup> ParseLookupOutput(std::string_view text, std::string& error)
{
    const nlohmann::json json = nlohmann::json::parse(text, nullptr, false);
    if (json.is_discarded() || !json.is_object() || !json.contains("lookups") || !json.at("lookups").is_array()) {
        error = "the lookup output is not {\"lookups\": [...]}";
        return {};
    }
    std::vector<Lookup> lookups;
    for (const nlohmann::json& entry : json.at("lookups")) {
        if (!entry.is_object() || !entry.contains("source") || !entry.at("source").is_string() ||
            !entry.contains("query") || !entry.at("query").is_string()) {
            error = "each lookup needs a string 'source' and 'query'";
            return {};
        }
        const std::string source = entry.at("source").get<std::string>();
        Lookup lookup;
        if (source == "lore") {
            lookup.source = store::EmbeddingKind::Lore;
        } else if (source == "history") {
            lookup.source = store::EmbeddingKind::Turn;
        } else if (source == "notes") {
            lookup.source = store::EmbeddingKind::Note;
        } else {
            error = std::format("unknown lookup source '{}'", source);
            return {};
        }
        lookup.query = entry.at("query").get<std::string>();
        lookups.push_back(std::move(lookup));
    }
    return lookups;
}
```

```cpp
#include <chrono>

namespace morpheus::test {

// A backend for turn-layer tests. Tokens are counted like FakeBackend. Complete asks the responder for the reply,
// streams it in pieces of about 4 bytes that never split a UTF-8 character (stopping early when `stop` is
// requested), and records the call. Embed maps a text to a bag of words (lower-cased [a-z0-9] runs hashed into
// EMBED_DIMS dimensions, L2-normalized), so texts sharing words score higher. Save/RestoreState keep nothing.
class ScriptedBackend final : public FakeBackend {
public:
    using Responder = std::function<std::string(const inference::Prompt&, const inference::GenerationSpec&)>;

    struct Call {
        inference::Prompt prompt = {};
        inference::GenerationSpec spec = {};
    };

    static constexpr std::size_t EMBED_DIMS = 64;

private:
    Responder _responder = {};
    std::vector<Call> _calls = {};
    int _embeddedTexts = 0;
    std::size_t _embedLimit = 0; // Longest text Embed accepts, in bytes; 0 means no limit.
    std::chrono::milliseconds _pieceDelay = std::chrono::milliseconds(0);

public:
    explicit ScriptedBackend(int contextSize, Responder responder = {})
        : FakeBackend(contextSize)
        , _responder(std::move(responder))
    {
    }

    const std::vector<Call>& Calls() const
    {
        return _calls;
    }

    // Texts embedded so far, across calls.
    int EmbeddedTexts() const
    {
        return _embeddedTexts;
    }

    // Embed throws InferenceError for a text longer than `bytes` (an embedding context that is too small).
    void SetEmbedLimit(std::size_t bytes)
    {
        _embedLimit = bytes;
    }

    // Sleeps before each streamed piece, so tests can cancel mid-reply.
    void SetPieceDelay(std::chrono::milliseconds delay)
    {
        _pieceDelay = delay;
    }

    inference::Completion Complete(const inference::Prompt& prompt, const inference::GenerationSpec& spec,
                                   const inference::TokenCallback& onToken, std::stop_token stop) override
    {
        MORPHEUS_REQUIRE(static_cast<bool>(_responder), "ScriptedBackend: no responder for Complete");
        _calls.push_back({prompt, spec});
        const std::string reply = _responder(prompt, spec);

        inference::Completion completion;
        completion.promptTokens = CountPromptTokens(prompt);
        completion.tokensEvaluated = completion.promptTokens;
        std::size_t at = 0;
        while (at < reply.size()) {
            if (_pieceDelay.count() > 0) {
                std::this_thread::sleep_for(_pieceDelay);
            }
            if (stop.stop_requested()) {
                completion.cancelled = true;
                return completion;
            }
            std::size_t end = std::min(at + 4, reply.size());
            while (end < reply.size() && (static_cast<unsigned char>(reply[end]) & 0xC0) == 0x80) {
                ++end; // Never end a piece inside a UTF-8 character.
            }
            const std::string_view piece = std::string_view(reply).substr(at, end - at);
            completion.text += piece;
            ++completion.tokensGenerated;
            if (onToken) {
                onToken(piece);
            }
            at = end;
        }
        return completion;
    }

    std::vector<std::vector<float>> Embed(const std::vector<std::string>& texts, inference::EmbedPurpose) override
    {
        std::vector<std::vector<float>> vectors;
        for (const std::string& text : texts) {
            if (_embedLimit != 0 && text.size() > _embedLimit) {
                throw inference::InferenceError(std::format("text of {} bytes is over the embedding limit", text.size()));
            }
            ++_embeddedTexts;
            std::vector<float> vector(EMBED_DIMS, 0.0f);
            std::string word;
            auto flush = [&] {
                if (!word.empty()) {
                    core::ContentHash hash;
                    hash.Add(word);
                    vector[hash.Value() % EMBED_DIMS] += 1.0f;
                    word.clear();
                }
            };
            for (const char c : text) {
                const char lower = (c >= 'A' && c <= 'Z') ? static_cast<char>(c - 'A' + 'a') : c;
                if ((lower >= 'a' && lower <= 'z') || (lower >= '0' && lower <= '9')) {
                    word += lower;
                } else {
                    flush();
                }
            }
            flush();
            float norm = 0.0f;
            for (const float value : vector) {
                norm += value * value;
            }
            if (norm > 0.0f) {
                for (float& value : vector) {
                    value /= std::sqrt(norm);
                }
            }
            vectors.push_back(std::move(vector));
        }
        return vectors;
    }

    std::string EmbeddingModelId() const override
    {
        return "scripted-embed";
    }

    std::vector<std::uint8_t> SaveState() override
    {
        return {};
    }

    void RestoreState(std::span<const std::uint8_t>) override
    {
    }
};

} // namespace morpheus::test
```

```cpp
        store::EmbeddingKind kind = store::EmbeddingKind::Lore;
        std::string refId = {};

        std::string text = {}; // The snippet the prompt shows.

        std::string text = {}; // Exactly what is embedded.
```

```cpp
std::string Lowered(std::string_view text)
{

    for (char& c : result) {
        if (c >= 'A' && c <= 'Z') {

void MemoryIndex::SyncLore(const core::World& world, store::RunStore& store, inference::LlmBackend& backend)
{
    std::vector<Document> documents;
    std::vector<Entry> entries;
    std::set<std::string> subjects;
    for (const core::LoreEntry& lore : world.lore) {
        if (lore.alwaysOn) {
            continue; // Always in L1.
        }
        if (!subjects.insert(lore.subject).second) {
            throw core::DataError(
                std::format("world '{}': lore.csv has two entries for subject '{}'", world.id, lore.subject));
        }
        const std::string text = lore.subject + ": " + lore.data;
        documents.push_back({lore.subject, text});
        entries.push_back({store::EmbeddingKind::Lore, lore.subject, Lowered(lore.subject), text, {}});
    }
    std::vector<std::vector<float>> vectors = Vectors(store::EmbeddingKind::Lore, documents, store, backend);
    for (std::size_t i = 0; i < entries.size(); ++i) {
        entries[i].vector = std::move(vectors[i]);
    }
    Replace(store::EmbeddingKind::Lore, std::move(entries));
}

void MemoryIndex::SyncHistory(store::RunStore& store, int foldedThrough, inference::LlmBackend& backend)
{
    MORPHEUS_REQUIRE(foldedThrough >= 0, "SyncHistory: foldedThrough must be >= 0");

    std::vector<Document> turnDocuments;
    std::vector<Entry> turnEntries;
    if (foldedThrough > 0) {
        for (const core::TurnRecord& turn : store.Turns(1, foldedThrough)) {
            const std::string refId = std::to_string(turn.number);
            turnDocuments.push_back({refId, core::CutUtf8(turn.input + "\n" + turn.narration, EMBED_TEXT_CHARS)});
            turnEntries.push_back({store::EmbeddingKind::Turn, refId, {},
                                   std::format("Turn {}: {} -> {}", turn.number,
                                               core::CutUtf8(turn.input, HISTORY_SNIPPET_CHARS),
                                               core::CutUtf8(turn.narration, HISTORY_SNIPPET_CHARS)),
                                   {}});
        }
    }

    std::vector<Document> noteDocuments;
    std::vector<Entry> noteEntries;
    std::map<int, int> notesPerTurn;
    for (const core::Note& note : store.Notes()) {
        const std::string refId = std::format("{}.{}", note.turn, notesPerTurn[note.turn]++);
        noteDocuments.push_back({refId, core::CutUtf8(note.text, EMBED_TEXT_CHARS)});
        noteEntries.push_back({store::EmbeddingKind::Note, refId, {},
                               std::format("Note from turn {}: {}", note.turn, note.text), {}});
    }

    std::vector<std::vector<float>> turnVectors = Vectors(store::EmbeddingKind::Turn, turnDocuments, store, backend);
    for (std::size_t i = 0; i < turnEntries.size(); ++i) {
        turnEntries[i].vector = std::move(turnVectors[i]);
    }
    std::vector<std::vector<float>> noteVectors = Vectors(store::EmbeddingKind::Note, noteDocuments, store, backend);
    for (std::size_t i = 0; i < noteEntries.size(); ++i) {
        noteEntries[i].vector = std::move(noteVectors[i]);
    }
    Replace(store::EmbeddingKind::Turn, std::move(turnEntries));
    Replace(store::EmbeddingKind::Note, std::move(noteEntries));
}

std::vector<RetrievalHit> MemoryIndex::Retrieve(std::string_view query, std::span<const store::EmbeddingKind> sources,
                                                int capTokens, std::size_t maxHits,
                                                inference::LlmBackend& backend) const
{
    auto searched = [&sources](store::EmbeddingKind kind) {
        return std::find(sources.begin(), sources.end(), kind) != sources.end();
    };
    const bool anything = std::any_of(_entries.begin(), _entries.end(), [&](const Entry& e) { return searched(e.kind); });
    if (!anything || capTokens <= 0 || maxHits == 0 || query.empty()) {
        return {};
    }

    const std::vector<float> queryVector =
        backend.Embed({std::string(query)}, inference::EmbedPurpose::Query).at(0);
    const std::string loweredQuery = Lowered(query);
    std::vector<RetrievalHit> hits;
    for (const Entry& entry : _entries) {
        if (!searched(entry.kind)) {
            continue;
        }
        MORPHEUS_REQUIRE(entry.vector.size() == queryVector.size(), "Retrieve: vectors from different models");
        float score = 0.0f;
        for (std::size_t i = 0; i < queryVector.size(); ++i) {
            score += queryVector[i] * entry.vector[i]; // Both are L2-normalized: the dot product is the cosine.
        }
        if (!entry.name.empty() && loweredQuery.find(entry.name) != std::string::npos) {
            score += NAME_BOOST;
        }
        if (score >= RETRIEVAL_MIN_SCORE) {
            hits.push_back({entry.kind, entry.refId, entry.text, score});
        }
    }
    std::sort(hits.begin(), hits.end(), [](const RetrievalHit& a, const RetrievalHit& b) {
        if (a.score != b.score) {
            return a.score > b.score;
        }
        if (a.kind != b.kind) {
            return a.kind < b.kind;
        }
        return a.refId < b.refId;
    });

    std::vector<RetrievalHit> kept;
    int used = 0;
    for (RetrievalHit& hit : hits) {
        if (kept.size() == maxHits) {
            break;
        }
        const int cost = backend.CountTokens("- " + hit.text + "\n");
        if (used + cost > capTokens) {
            continue;
        }
        used += cost;
        kept.push_back(std::move(hit));
    }
    return kept;
}

std::vector<std::vector<float>> MemoryIndex::Vectors(store::EmbeddingKind kind, const std::vector<Document>& documents,
                                                     store::RunStore& store, inference::LlmBackend& backend) const
{
    const std::string model = backend.EmbeddingModelId();
    std::map<std::string, store::EmbeddingRow> stored;
    for (store::EmbeddingRow& row : store.Embeddings(kind, model)) {
        std::string refId = row.refId;
        stored.emplace(std::move(refId), std::move(row));
    }

    std::vector<std::vector<float>> vectors;
    vectors.reserve(documents.size());
    for (const Document& document : documents) {
        core::ContentHash hash;
        hash.Add(_documentPrefix);
        hash.Add(document.text);
        const auto it = stored.find(document.refId);
        if (it != stored.end() && it->second.contentHash == hash.Hex()) {
            vectors.push_back(it->second.vector);
            continue;
        }
        std::vector<float> vector;
        try {
            vector = backend.Embed({document.text}, inference::EmbedPurpose::Document).at(0);
        } catch (const inference::InferenceError& error) {
            throw core::DataError(std::format("{} '{}' cannot be embedded: {}",
                                              kind == store::EmbeddingKind::Lore ? "lore.csv entry" : "memory",
                                              document.refId, error.what()));
        }
        store.PutEmbedding({kind, document.refId, model, vector, hash.Hex()});
        vectors.push_back(std::move(vector));
    }
    return vectors;
}

void MemoryIndex::Replace(store::EmbeddingKind kind, std::vector<Entry> entries)
{
    std::erase_if(_entries, [kind](const Entry& entry) { return entry.kind == kind; });
    _entries.insert(_entries.end(), std::make_move_iterator(entries.begin()), std::make_move_iterator(entries.end()));
}
```

```cpp
// The summary text from a completion: trimmed; a model that wrote nothing still leaves a marker, not a blank.
std::string SummaryText(const std::string& output)
{
    std::string text = core::Trim(output);
    return text.empty() ? std::string("(no summary)") : text;

std::optional<core::Summary> SummarizeTurns(const inference::Message& systemMessage,
                                            const std::vector<core::TurnRecord>& turns,
                                            const inference::GenerationSpec& spec, inference::LlmBackend& backend,
                                            std::stop_token stop)
{
    MORPHEUS_REQUIRE(systemMessage.role == inference::Role::System && !turns.empty(),
                     "SummarizeTurns: needs the system message and at least one turn");
    inference::Prompt prompt;
    prompt.messages.push_back(systemMessage);
    for (inference::Message& message : context::RenderTranscript(turns)) {
        prompt.messages.push_back(std::move(message));
    }
    prompt.stableCount = prompt.messages.size();
    prompt.messages.push_back({inference::Role::User, std::string(SUMMARIZE_INSTRUCTION)});

    const inference::Completion completion = backend.Complete(prompt, spec, {}, stop);
    if (completion.cancelled) {
        return std::nullopt;
    }
    return core::Summary{turns.front().number, turns.back().number, SummaryText(completion.text)};
}

std::optional<core::Summary> CondenseSummaries(const inference::Message& systemMessage,
                                               const std::vector<core::Summary>& summaries,
                                               const inference::GenerationSpec& spec, inference::LlmBackend& backend,
                                               std::stop_token stop)
{
    MORPHEUS_REQUIRE(systemMessage.role == inference::Role::System && !summaries.empty(),
                     "CondenseSummaries: needs the system message and at least one summary");
    inference::Prompt prompt;
    prompt.messages.push_back(systemMessage);
    prompt.stableCount = 1;
    prompt.messages.push_back({inference::Role::User, std::string(CONDENSE_INSTRUCTION)});

    const inference::Completion completion = backend.Complete(prompt, spec, {}, stop);
    if (completion.cancelled) {
        return std::nullopt;
    }
    return core::Summary{summaries.front().fromTurn, summaries.back().toTurn, SummaryText(completion.text)};
}
```

```cpp
// A turn that cannot run as asked: nothing to undo or regenerate, an empty input, or an input too long for the
// tail allowance. Nothing changed; the message is for the player.
class TurnError : public std::runtime_error {
public:
    using std::runtime_error::runtime_error;
};

constexpr std::size_t RETRIEVAL_MAX_HITS = 6; // Retrieval hits in the tail (T2), before retrieval_cap applies.
constexpr std::size_t LOOKUP_MAX_HITS = 2;    // Hits each assisted-mode lookup adds.
constexpr int LOOKUP_MAX_TOKENS = 192;        // Generation cap for the lookup call.
constexpr int FOLD_SUMMARY_DIVISOR = 4;       // A fold summary gets summary_cap / 4 tokens: several fit before a condense.
constexpr int CONDENSE_SUMMARY_DIVISOR = 2;   // A condensed summary gets summary_cap / 2 tokens, so it fits its cap.

struct TurnCallbacks {
    // After apply, before narrate: the record has its checks and applied and rejected changes, no narration yet.
    std::function<void(const core::TurnRecord&)> onResolved = {};
    inference::TokenCallback onNarrationToken = {};
};

// One open run: its world, settings, database and memory index, and the turn loop (architecture spec, "Turn flow").
// Every backend call happens inside these methods, on the caller's thread (the engine worker). Not thread-safe.
class Session {
private:
    core::World _world;     // Set by the constructor.
    core::Settings _settings;
    core::MemoryMode _mode = core::MemoryMode::Engine;
    store::RunStore _store; // Set by the constructor.
    inference::LlmBackend* _pBackend = nullptr; // Not owned; outlives the session.
    MemoryIndex _index;     // Set by the constructor.
    context::Assembly _lastAssembly = {};
    bool _worldChanged = false;

public:
    // Starts a new run in `file` from the world's initial state, with `seed` for dice and sampling, and indexes the
    // lore. Throws StoreError if the file exists, and DataError if lore cannot be embedded (then no file is left).
    static Session Start(core::World world, core::Settings settings, const std::filesystem::path& file,
                         std::uint64_t seed, inference::LlmBackend& backend);

    // Opens a run of `world`. Throws DataError if the run belongs to another world or its latest state no longer
    // validates against the world's schema. Edited world files set WorldChanged(); edited lore is re-embedded.
    static Session Load(core::World world, core::Settings settings, const std::filesystem::path& file,
                        inference::LlmBackend& backend);

    // Plays one turn: retrieve, (assisted mode: look up), resolve, apply, narrate, commit. Control characters other
    // than newline and tab are stripped from `input` and it is trimmed. Returns the committed record, or nullopt
    // when `stop` cancelled the turn (nothing is committed). Throws TurnError for an empty input or one that does
    // not fit, and InferenceError from the backend (nothing is committed).
    std::optional<core::TurnRecord> RunTurn(std::string_view input, const TurnCallbacks& callbacks,
                                            std::stop_token stop);

    // Removes the latest turn. Throws TurnError when there is none.
    void Undo();

    // Plays the latest turn's input again as a new attempt: same dice, newly sampled text. If it is cancelled or
    // fails, the previous turn is put back. Throws TurnError when there is no turn.
    std::optional<core::TurnRecord> Regenerate(const TurnCallbacks& callbacks, std::stop_token stop);

    // Between-turn upkeep: folds or condenses while the transcript or the summary is over budget, then indexes
    // folded turns and notes. Returns false if `stop` cancelled it (it can simply run again later).
    bool Maintain(std::stop_token stop);

    const store::RunMeta& Meta() const;
    bool WorldChanged() const;
    nlohmann::json State();                  // After the latest turn.
    std::vector<core::TurnRecord> History(); // Every committed turn, oldest first.
    std::vector<core::Summary> Summaries();
    const context::Assembly& LastAssembly() const; // The last resolve prompt, for the context inspector.

private:
    Session(core::World world, core::Settings settings, store::RunStore store, MemoryIndex index,
            inference::LlmBackend& backend);

    // RunTurn and Regenerate: plays turn LatestTurn()+1 for a cleaned input.
    std::optional<core::TurnRecord> PlayTurn(const std::string& input, int attempt, const TurnCallbacks& callbacks,
                                             std::stop_token stop);

    // The layers for one call: summaries and unfolded transcript from the store, then the given tail parts.
    context::ContextInputs Inputs(const nlohmann::json& state, const std::vector<RetrievalHit>& hits,
                                  const std::string& input, std::string_view instruction);

    // Assembles a prompt that fits, shedding hits, condensing and folding as needed (see the loop). nullopt when a
    // memory call was cancelled.
    std::optional<context::Assembly> AssembleFitting(const nlohmann::json& state, std::vector<RetrievalHit>& hits,
                                                     const std::string& input, std::string_view instruction, int turn,
                                                     int attempt, std::stop_token stop);

    // Folds the oldest half (at least one) of `transcript` into a new summary. False when cancelled.
    bool FoldOldest(const inference::Message& systemMessage, const std::vector<core::TurnRecord>& transcript, int turn,
                    int attempt, std::stop_token stop);

    // Replaces every summary with one condensed summary. False when cancelled.
    bool Condense(const inference::Message& systemMessage, int turn, int attempt, std::stop_token stop);

    // The last turn covered by a summary, 0 when none.
    int FoldedThrough();
};
```

```cpp
Session Session::Start(core::World world, core::Settings settings, const std::filesystem::path& file,
                       std::uint64_t seed, inference::LlmBackend& backend)
{
    store::RunMeta meta;
    meta.worldId = world.id;
    meta.worldHash = world.contentHash;
    meta.modelId = core::PathText(settings.chatModel.stem());
    meta.rngSeed = seed;
    meta.settings = core::SettingsToJson(settings);
    store::RunStore store = store::RunStore::Create(file, meta, world.initialState);

    MemoryIndex index(settings.embeddingDocumentPrefix);
    try {
        index.SyncLore(world, store, backend);
    } catch (...) {
        // The run never started: close the database (a moved-from store holds no handle), then remove the file.
        { store::RunStore closing = std::move(store); }
        std::error_code ignored;
        std::filesystem::remove(file, ignored);
        throw;
    }
    return Session(std::move(world), std::move(settings), std::move(store), std::move(index), backend);
}

Session Session::Load(core::World world, core::Settings settings, const std::filesystem::path& file,
                      inference::LlmBackend& backend)
{
    store::RunStore store = store::RunStore::Open(file);
    if (store.Meta().worldId != world.id) {
        throw core::DataError(std::format("run '{}' belongs to world '{}', not '{}'", core::PathText(file),
                                          store.Meta().worldId, world.id));
    }
    try {
        world.schema.ValidateState(store.StateAt(store.LatestTurn()));
    } catch (const core::DataError& error) {
        throw core::DataError(std::format("run '{}': its latest state no longer fits world '{}': {}",
                                          core::PathText(file), world.id, error.what()));
    }

    MemoryIndex index(settings.embeddingDocumentPrefix);
    index.SyncLore(world, store, backend);
    const bool worldChanged = store.Meta().worldHash != world.contentHash;
    Session session(std::move(world), std::move(settings), std::move(store), std::move(index), backend);
    session._worldChanged = worldChanged;
    session._index.SyncHistory(session._store, session.FoldedThrough(), backend);
    return session;
}

std::optional<core::TurnRecord> Session::RunTurn(std::string_view input, const TurnCallbacks& callbacks,
                                                 std::stop_token stop)
{
    // Control characters go (newline and tab stay): they have no place in a prompt, and U+001E is the backend's
    // content marker.
    std::string kept;
    for (const char c : input) {
        const auto byte = static_cast<unsigned char>(c);
        if ((byte >= 0x20 && byte != 0x7F) || c == '\n' || c == '\t') {
            kept += c;
        }
    }
    const std::string cleaned = core::Trim(kept);
    if (cleaned.empty()) {
        throw TurnError("the input is empty");
    }
    return PlayTurn(cleaned, 0, callbacks, stop);
}

void Session::Undo()
{
    const int latest = _store.LatestTurn();
    if (latest == 0) {
        throw TurnError("there is no turn to undo");
    }
    _store.TruncateAfter(latest - 1);
}

std::optional<core::TurnRecord> Session::Regenerate(const TurnCallbacks& callbacks, std::stop_token stop)
{
    const int latest = _store.LatestTurn();
    if (latest == 0) {
        throw TurnError("there is no turn to regenerate");
    }
    const core::TurnRecord previous = *_store.Turn(latest);
    const nlohmann::json previousState = _store.StateAt(latest);
    _store.TruncateAfter(latest - 1);
    try {
        std::optional<core::TurnRecord> record = PlayTurn(previous.input, previous.attempt + 1, callbacks, stop);
        if (!record) {
            _store.CommitTurn(previous, previousState);
        }
        return record;
    } catch (...) {
        _store.CommitTurn(previous, previousState);
        throw;
    }
}

bool Session::Maintain(std::stop_token stop)
{
    const int latest = _store.LatestTurn();
    const nlohmann::json state = _store.StateAt(latest);
    for (;;) {
        // The next input is unknown: a placeholder tail measures the stable layers. The turn checks the real tail.
        const context::ContextInputs inputs = Inputs(state, {}, std::string(MAINTENANCE_INPUT), RESOLVE_INSTRUCTION);
        const context::Assembly assembly = context::AssembleResolvePrompt(_world, inputs, _settings.budget, *_pBackend);
        if (assembly.summaryOverBudget) {
            if (!Condense(assembly.prompt.messages.front(), latest, 0, stop)) {
                return false;
            }
            continue;
        }
        if (assembly.transcriptOverBudget && !inputs.transcript.empty()) {
            if (!FoldOldest(assembly.prompt.messages.front(), inputs.transcript, latest, 0, stop)) {
                return false;
            }
            continue;
        }
        break;
    }
    _index.SyncHistory(_store, FoldedThrough(), *_pBackend);
    return true;
}

std::optional<core::TurnRecord> Session::PlayTurn(const std::string& input, int attempt, const TurnCallbacks& callbacks,
                                                  std::stop_token stop)
{
    const int turn = _store.LatestTurn() + 1;
    const nlohmann::json state = _store.StateAt(turn - 1);
    const std::uint64_t seed = _store.Meta().rngSeed;
    nlohmann::json telemetry = nlohmann::json::object();
    // Telemetry spelling of a memory kind, as the lookup call spells sources.
    auto kindText = [](store::EmbeddingKind kind) {
        switch (kind) {
        case store::EmbeddingKind::Lore:
            return "lore";
        case store::EmbeddingKind::Turn:
            return "history";
        case store::EmbeddingKind::Note:
            return "notes";
        }
        throw core::ContractError("PlayTurn: unhandled EmbeddingKind");
    };

    // 1. Retrieve.
    std::vector<RetrievalHit> hits =
        _index.Retrieve(input, ALL_SOURCES, _settings.budget.retrievalCap, RETRIEVAL_MAX_HITS, *_pBackend);

    // 2. Resolve.
    std::optional<context::Assembly> assembly =
        AssembleFitting(state, hits, input, RESOLVE_INSTRUCTION, turn, attempt, stop);
    if (!assembly) {
        return std::nullopt;
    }
    _lastAssembly = *assembly;
    inference::GenerationSpec resolveSpec;
    resolveSpec.grammar = BuildResolveGrammar(_world, state, _mode);
    resolveSpec.maxTokens = _settings.budget.resolveMaxTokens;
    resolveSpec.sampling =
        inference::SamplingFrom(_settings.resolveSampling, core::SamplingSeed(seed, turn, core::CallKind::Resolve, attempt));
    const inference::Completion resolved = _pBackend->Complete(assembly->prompt, resolveSpec, {}, stop);
    if (resolved.cancelled) {
        return std::nullopt;
    }

    // 3. Apply.
    const ResolveProposal proposal = ParseResolveOutput(resolved.text);
    Resolution resolution = ApplyProposal(_world, state, proposal, seed, turn);
    core::TurnRecord record;
    record.number = turn;
    record.attempt = attempt;
    record.input = input;
    const nlohmann::json parsed = nlohmann::json::parse(resolved.text, nullptr, false);
    record.resolve = parsed.is_discarded() ? nlohmann::json{{"unparsed", resolved.text}} : parsed;
    record.checks = resolution.checks;
    record.applied = resolution.applied;
    record.rejected = resolution.rejected;
    if (_mode == core::MemoryMode::Assisted) {
        record.notes = proposal.notes;
    }
    if (callbacks.onResolved) {
        callbacks.onResolved(record);
    }

    // 4. Narrate: the resolve prompt plus the resolve output and the resolution record, so all of it stays cached.
    inference::Prompt narratePrompt = assembly->prompt;
    context::ExtendForNarrate(narratePrompt, resolved.text,
                              RenderNarrateMessage(proposal, resolution, _settings.budget.narrateAllowance, *_pBackend));
    inference::GenerationSpec narrateSpec;
    narrateSpec.maxTokens = _settings.budget.narrateMaxTokens;
    narrateSpec.sampling =
        inference::SamplingFrom(_settings.narrateSampling, core::SamplingSeed(seed, turn, core::CallKind::Narrate, attempt));
    const inference::Completion narrated =
        _pBackend->Complete(narratePrompt, narrateSpec, callbacks.onNarrationToken, stop);
    if (narrated.cancelled) {
        return std::nullopt;
    }
    record.narration = core::Trim(narrated.text);

    // 5. Commit.
    telemetry["resolve"] = Telemetry(resolved);
    telemetry["narrate"] = Telemetry(narrated);
    telemetry["retrieval"] = nlohmann::json::array(); // The hits that made it into the prompt.
    for (const RetrievalHit& hit : hits) {
        telemetry["retrieval"].push_back({{"source", kindText(hit.kind)}, {"ref", hit.refId}, {"score", hit.score}});
    }
    record.timings = std::move(telemetry);
    _store.CommitTurn(record, resolution.state);
    return record;
}

context::ContextInputs Session::Inputs(const nlohmann::json& state, const std::vector<RetrievalHit>& hits,
                                       const std::string& input, std::string_view instruction)
{
    context::ContextInputs inputs;
    inputs.engineRules = std::string(ENGINE_RULES);
    if (_mode == core::MemoryMode::Assisted) {
        inputs.engineRules += "\n\n" + std::string(ASSISTED_RULES);
    }
    inputs.summaries = _store.Summaries();
    const int latest = _store.LatestTurn();
    const int firstUnfolded = FoldedThrough() + 1;
    if (firstUnfolded <= latest) {
        inputs.transcript = _store.Turns(firstUnfolded, latest);
    }
    inputs.state = state;
    for (const RetrievalHit& hit : hits) {
        inputs.retrieved.push_back(hit.text);
    }
    inputs.playerInput = input;
    inputs.instruction = std::string(instruction);
    return inputs;
}

std::optional<context::Assembly> Session::AssembleFitting(const nlohmann::json& state, std::vector<RetrievalHit>& hits,
                                                          const std::string& input, std::string_view instruction,
                                                          int turn, int attempt, std::stop_token stop)
{
    // Every pass sheds a hit, condenses the summary below its cap, or folds turns, so the loop ends.
    for (;;) {
        const context::ContextInputs inputs = Inputs(state, hits, input, instruction);
        context::Assembly assembly = context::AssembleResolvePrompt(_world, inputs, _settings.budget, *_pBackend);
        if (assembly.Fits()) {
            return assembly;
        }
        if (assembly.tailOverBudget) {
            if (hits.empty()) {
                throw TurnError(std::format("the input and the state use {} tokens, over tail_allowance {}",
                                            assembly.tokens.tail, _settings.budget.tailAllowance));
            }
            hits.pop_back();
            continue;
        }
        if (assembly.summaryOverBudget) {
            if (!Condense(assembly.prompt.messages.front(), turn, attempt, stop)) {
                return std::nullopt;
            }
            continue;
        }
        // The transcript is over its budget, or the whole prompt overflows. contextOverflow is the authoritative fit
        // check: transcriptBudget leaves out a few template tokens that it counts.
        if (!inputs.transcript.empty()) {
            if (!FoldOldest(assembly.prompt.messages.front(), inputs.transcript, turn, attempt, stop)) {
                return std::nullopt;
            }
            continue;
        }
        if (!hits.empty()) {
            hits.pop_back();
            continue;
        }
        throw TurnError("the prompt does not fit context_size even without transcript or retrieval");
    }
}

bool Session::FoldOldest(const inference::Message& systemMessage, const std::vector<core::TurnRecord>& transcript,
                         int turn, int attempt, std::stop_token stop)
{
    const std::size_t count = std::max<std::size_t>(1, transcript.size() / 2);
    const std::vector<core::TurnRecord> oldest(transcript.begin(),
                                               transcript.begin() + static_cast<std::ptrdiff_t>(count));
    inference::GenerationSpec spec;
    spec.maxTokens = std::max(1, _settings.budget.summaryCap / FOLD_SUMMARY_DIVISOR);
    spec.sampling = inference::SamplingFrom(
        _settings.resolveSampling, core::SamplingSeed(_store.Meta().rngSeed, turn, core::CallKind::Summarize, attempt));
    const std::optional<core::Summary> summary = SummarizeTurns(systemMessage, oldest, spec, *_pBackend, stop);
    if (!summary) {
        return false;
    }
    _store.AddSummary(*summary);
    // Folded turns leave the transcript, so they become searchable history.
    _index.SyncHistory(_store, summary->toTurn, *_pBackend);
    return true;
}

bool Session::Condense(const inference::Message& systemMessage, int turn, int attempt, std::stop_token stop)
{
    inference::GenerationSpec spec;
    spec.maxTokens = std::max(1, _settings.budget.summaryCap / CONDENSE_SUMMARY_DIVISOR);
    spec.sampling = inference::SamplingFrom(

    return true;
```

```cpp
                           MaintenanceFailed, Error>;

// Whether `event` ends the command it belongs to.
bool IsClosing(const Event& event);

// The engine worker thread (architecture spec, "Process and modules"): the only thread that touches the backend
// and the open run. Commands run one at a time in order. After a committed turn, while no command waits, the
// worker runs Session::Maintain; a new command preempts it.
class Worker {
private:
    core::Settings _settings;
    inference::LlmBackend* _pBackend = nullptr; // Not owned; used only on the worker thread.
    std::mutex _mutex = {};
    std::condition_variable_any _commandPosted = {};
    std::condition_variable _eventPosted = {};
    std::deque<Command> _commands = {};
    std::deque<Event> _events = {};

    bool _maintaining = false;            // The running job is maintenance, which a new command preempts.
    std::optional<Session> _session = {}; // Worker thread only.
    std::jthread _thread = {};            // Last: starts after every other member exists, and is joined first.

    Worker& operator=(const Worker&) = delete;

    void Post(Command command);

    // Cancels the running command (it ends with TurnCancelled) or maintenance. No effect when idle.
    void Cancel();

    // Every event so far, oldest first. Never blocks: for the UI's frame loop.
    std::vector<Event> PollEvents();

    // The next event, waiting up to `timeout`.
    std::optional<Event> WaitEvent(std::chrono::milliseconds timeout);

private:
    void Run(std::stop_token shutdown);

    // Emits TurnCompleted or TurnCancelled for a turn's result. Returns whether it committed.
    bool FinishTurn(const std::optional<core::TurnRecord>& record);
```

Create `src/turn/Worker.cpp`:

```cpp
#include "turn/Worker.h"

#include <exception>
#include <string_view>
#include <utility>

#include "core/Errors.h"
#include "core/World.h"

namespace morpheus::turn {

bool IsClosing(const Event& event)
{
    return std::holds_alternative<RunOpened>(event) || std::holds_alternative<TurnCompleted>(event) ||
           std::holds_alternative<TurnCancelled>(event) || std::holds_alternative<StateChanged>(event) ||
           std::holds_alternative<Error>(event);
}

Worker::Worker(core::Settings settings, inference::LlmBackend& backend)
    : _settings(std::move(settings))
    , _pBackend(&backend)
    , _thread([this](std::stop_token shutdown) { Run(shutdown); })
{
}

void Worker::Post(Command command)
{
    {
        std::scoped_lock lock(_mutex);
        _commands.push_back(std::move(command));
        if (_maintaining) {
            _jobStop.request_stop(); // A command preempts between-turn maintenance.
        }
    }
    _commandPosted.notify_one();
}

void Worker::Cancel()
{
    std::scoped_lock lock(_mutex);
    _jobStop.request_stop();
}

std::vector<Event> Worker::PollEvents()
{
    std::scoped_lock lock(_mutex);
    std::vector<Event> events(std::make_move_iterator(_events.begin()), std::make_move_iterator(_events.end()));
    _events.clear();
    return events;
}

std::optional<Event> Worker::WaitEvent(std::chrono::milliseconds timeout)
{
    std::unique_lock lock(_mutex);
    if (!_eventPosted.wait_for(lock, timeout, [this] { return !_events.empty(); })) {
        return std::nullopt;
    }
    Event event = std::move(_events.front());
    _events.pop_front();
    return event;
}

void Worker::Run(std::stop_token shutdown)
{
    // Runs one command and emits its events. Returns true when it committed a turn (maintenance is due).
    auto execute = [this](const Command& command, std::stop_token stop) {
        try {
            if (const auto* pStart = std::get_if<StartRun>(&command)) {
                _session.reset(); // Close the previous run first.
                _session.emplace(Session::Start(core::LoadWorld(pStart->worldFolder), _settings, pStart->runFile,
                                                pStart->seed, *_pBackend));
                EmitOpened();
                return false;
            }
            if (const auto* pLoad = std::get_if<LoadRun>(&command)) {
                _session.reset();
                _session.emplace(
                    Session::Load(core::LoadWorld(pLoad->worldFolder), _settings, pLoad->runFile, *_pBackend));
                EmitOpened();
                return false;
            }
            if (!_session) {
                throw TurnError("no run is open");
            }
            if (const auto* pInput = std::get_if<SubmitInput>(&command)) {
                return FinishTurn(_session->RunTurn(pInput->text, Callbacks(), stop));
            }
            if (std::holds_alternative<UndoTurn>(command)) {
                _session->Undo();
                Emit(StateChanged{_session->History(), _session->State()});
                return false;
            }
            return FinishTurn(_session->Regenerate(Callbacks(), stop));
        } catch (const core::ContractError& error) {
            Emit(Error{std::string("engine bug: ") + error.what()});
        } catch (const std::exception& error) {
            Emit(Error{error.what()});
        }
        return false;
    };

    // Shutdown cancels the running job too, so destroying the worker never waits for a whole turn.
    std::stop_callback cancelOnShutdown(shutdown, [this] { Cancel(); });
    bool maintenanceDue = false;
    for (;;) {
        std::optional<Command> command;
        std::stop_token stop;
        {
            std::unique_lock lock(_mutex);
            if (!maintenanceDue && !_commandPosted.wait(lock, shutdown, [this] { return !_commands.empty(); })) {
                return; // Shutdown while idle.
            }
            if (shutdown.stop_requested()) {
                return;
            }
            if (!_commands.empty()) {
                command = std::move(_commands.front());
                _commands.pop_front();
            }
            _jobStop = std::stop_source();
            _maintaining = !command.has_value();
            stop = _jobStop.get_token();
        }
        if (command) {
            maintenanceDue = execute(*command, stop);
        } else {
            try {
                if (_session) {
                    _session->Maintain(stop);
                }
            } catch (const std::exception& error) {
                Emit(MaintenanceFailed{error.what()});
            }
            maintenanceDue = false;
        }
    }
}

bool Worker::FinishTurn(const std::optional<core::TurnRecord>& record)
{
    if (!record) {
        Emit(TurnCancelled{});
        return false;
    }
    Emit(TurnCompleted{*record, _session->State(), _session->LastAssembly()});
    return true;
}

void Worker::EmitOpened()
{
    Emit(RunOpened{_session->Meta(), _session->History(), _session->State(), _session->WorldChanged()});
}

TurnCallbacks Worker::Callbacks()
{
    TurnCallbacks callbacks;
    callbacks.onResolved = [this](const core::TurnRecord& record) { Emit(TurnResolved{record}); };
    callbacks.onNarrationToken = [this](std::string_view piece) { Emit(TokenStreamed{std::string(piece)}); };
    return callbacks;
}

void Worker::Emit(Event event)
{
    {
        std::scoped_lock lock(_mutex);
        _events.push_back(std::move(event));
    }
    _eventPosted.notify_all();
}
```

Fixture format (`tests/data/replays/*.json`):

```
{"world": "<folder relative to the repo root>", "seed": N, "memory_mode": "engine" | "assisted",
 "steps": [{"input": "..."} | {"undo": true} | {"regenerate": true}],
 "replies": {"lookup": [...], "resolve": [...], "narrate": [...], "summarize": [...]},
 "expected": {"turns": [{"number", "input", "checks", "applied", "rejected", "narration"}], "final_state": {...}}}
```

Replies are recorded as strings, exactly as the model wrote them. A hand-written fixture may give a resolve reply as a JSON object, which is replayed as its `dump()`.

Replaying does not reproduce prompts: retrieval and fold timing depend on the embedding model and the tokenizer. It does reproduce every committed result, because those depend only on the replies, the seed and the engine:
- checks and rolls;
- applied and rejected changes;
- narration and state.

When fold timing differs, a replay that runs out of recorded summaries gets "Summary.".

```cpp
namespace morpheus::turn {

core::CallKind CallKindOf(const inference::Prompt& prompt, const inference::GenerationSpec& spec)
{
    if (!spec.grammar.empty()) {
        return spec.grammar.find("lookups") != std::string::npos ? core::CallKind::Lookup : core::CallKind::Resolve;
    }
    const std::string& last = prompt.messages.empty() ? std::string() : prompt.messages.back().content;
    if (last == SUMMARIZE_INSTRUCTION || last == CONDENSE_INSTRUCTION) {
        return core::CallKind::Summarize;
    }
    return core::CallKind::Narrate;
}

std::string CallKindName(core::CallKind kind)
{
    switch (kind) {
    case core::CallKind::Lookup:
        return "lookup";
    case core::CallKind::Resolve:
        return "resolve";
    case core::CallKind::Narrate:
        return "narrate";
    case core::CallKind::Summarize:
        return "summarize";
    }
    throw core::ContractError("CallKindName: unhandled CallKind");
}

nlohmann::json TurnResultJson(const core::TurnRecord& record)
{
    nlohmann::json checks = nlohmann::json::array();
    for (const core::CheckOutcome& check : record.checks) {
        checks.push_back(core::CheckOutcomeToJson(check));
    }
    nlohmann::json applied = nlohmann::json::array();
    for (const core::AppliedChange& change : record.applied) {
        applied.push_back(core::AppliedChangeToJson(change));
    }
    nlohmann::json rejected = nlohmann::json::array();
    for (const core::RejectedChange& change : record.rejected) {
        rejected.push_back(core::RejectedChangeToJson(change));
    }
    return {{"number", record.number}, {"input", record.input}, {"checks", checks},
            {"applied", applied},      {"rejected", rejected},  {"narration", record.narration}};
}

nlohmann::json MakeReplayFixture(const std::string& worldFolder, std::uint64_t seed, core::MemoryMode mode,
                                 const std::vector<ReplayStep>& steps, const RecordingBackend& recording,
                                 const std::vector<core::TurnRecord>& history, const nlohmann::json& finalState)
{
    nlohmann::json stepsJson = nlohmann::json::array();
    for (const ReplayStep& step : steps) {
        switch (step.action) {
        case ReplayStep::Action::Input:
            stepsJson.push_back({{"input", step.input}});
            break;
        case ReplayStep::Action::Undo:
            stepsJson.push_back({{"undo", true}});
            break;
        case ReplayStep::Action::Regenerate:
            stepsJson.push_back({{"regenerate", true}});
            break;
        }
    }
    nlohmann::json replies = nlohmann::json::object();
    for (const auto& [kind, texts] : recording.Replies()) {
        replies[CallKindName(kind)] = texts;
    }
    nlohmann::json turns = nlohmann::json::array();
    for (const core::TurnRecord& record : history) {
        turns.push_back(TurnResultJson(record));
    }
    return {{"world", worldFolder},
            {"seed", seed},
            {"memory_mode", mode == core::MemoryMode::Engine ? "engine" : "assisted"},
            {"steps", stepsJson},
            {"replies", replies},
            {"expected", {{"turns", turns}, {"final_state", finalState}}}};
}
```

```cpp
// Usage: morpheus_play <settings.json> <world folder> <run.db> [--seed N] [--record <fixture.json>]

constexpr std::string_view USAGE =
    "usage: morpheus_play <settings.json> <world folder> <run.db> [--seed N] [--record <fixture.json>]\n";

// What the player has seen of the run, kept from the events for /state and the replay fixture.
struct RunView {
    std::vector<core::TurnRecord> history = {};
    nlohmann::json state = nullptr;
};

// Prints one command's events up to its closing event and updates `view`. Returns false if it closed with an Error.
bool PrintUntilClosing(turn::Worker& worker, RunView& view)
{
    for (;;) {
        const std::optional<turn::Event> event = worker.WaitEvent(std::chrono::milliseconds(100));
        if (!event) {
            continue;
        }
        if (const auto* pPiece = std::get_if<turn::TokenStreamed>(&*event)) {
            std::cout << pPiece->piece << std::flush;
        } else if (const auto* pResolved = std::get_if<turn::TurnResolved>(&*event)) {
            const std::string mechanics = context::RenderMechanicsLine(pResolved->record);
            if (!mechanics.empty()) {
                std::cout << mechanics << '\n';
            }
            for (const core::RejectedChange& rejected : pResolved->record.rejected) {
                std::cout << "  (rejected: " << rejected.reason << ")\n";
            }
            std::cout << '\n';
        } else if (const auto* pFailed = std::get_if<turn::MaintenanceFailed>(&*event)) {
            std::cerr << "maintenance: " << pFailed->message << '\n';
        } else if (const auto* pCompleted = std::get_if<turn::TurnCompleted>(&*event)) {
            // "[resolve 41 tok in 830 ms (49.4 tok/s), narrate 120 tok in 2100 ms; prompt 2311 tok, 2290 reused]"
            const nlohmann::json& resolve = pCompleted->record.timings.at("resolve");
            const nlohmann::json& narrate = pCompleted->record.timings.at("narrate");
            const int resolveTokens = resolve.at("generated").get<int>();
            const double resolveMs = resolve.at("generate_ms").get<double>();
            std::cout << std::format("\n[resolve {} tok in {:.0f} ms ({:.1f} tok/s), narrate {} tok in {:.0f} ms; "
                                     "prompt {} tok, {} reused]\n",
                                     resolveTokens, resolveMs, resolveTokens * 1000.0 / std::max(1.0, resolveMs),
                                     narrate.at("generated").get<int>(), narrate.at("generate_ms").get<double>(),
                                     resolve.at("prompt_tokens").get<int>(), resolve.at("reused").get<int>());
            if (!view.history.empty() && view.history.back().number == pCompleted->record.number) {
                view.history.back() = pCompleted->record; // A regenerated turn replaces the last one.
            } else {
                view.history.push_back(pCompleted->record);
            }
            view.state = pCompleted->state;
            return true;
        } else if (const auto* pOpened = std::get_if<turn::RunOpened>(&*event)) {
            std::cout << std::format("{} turn(s) played in world '{}'.{}\n", pOpened->history.size(),
                                     pOpened->meta.worldId,
                                     pOpened->worldChanged ? " The world's files changed since this run started." : "");
            if (!pOpened->history.empty()) {
                std::cout << '\n' << pOpened->history.back().narration << '\n';
            }
            view.history = pOpened->history;
            view.state = pOpened->state;
            return true;
        } else if (const auto* pChanged = std::get_if<turn::StateChanged>(&*event)) {
            std::cout << std::format("Back to turn {}.\n", pChanged->history.size());
            view.history = pChanged->history;
            view.state = pChanged->state;
            return true;
        } else if (std::holds_alternative<turn::TurnCancelled>(*event)) {
            std::cout << "\n[cancelled]\n";
            return true;
        } else {
            std::cerr << "error: " << std::get<turn::Error>(*event).message << '\n';
            return false;
        }
    }
}

} // namespace

int main(int argc, char** argv)
{
    if (argc < 4) {
        std::cerr << USAGE;
        return 2;
    }
    std::optional<std::uint64_t> seed;
    std::optional<std::filesystem::path> recordFile;
    for (int i = 4; i < argc; ++i) {
        const std::string_view arg = argv[i];
        if (arg == "--seed" && i + 1 < argc) {
            seed = std::stoull(argv[++i]);
        } else if (arg == "--record" && i + 1 < argc) {
            recordFile = argv[++i];
        } else {
            std::cerr << USAGE;
            return 2;
        }
    }

    try {
        const core::Settings settings = core::LoadSettings(argv[1]);
        const std::filesystem::path worldFolder = argv[2];
        const std::filesystem::path runFile = argv[3];
        const bool resume = std::filesystem::exists(runFile);
        if (resume && recordFile) {
            std::cerr << "--record needs a new run file\n";
            return 2;
        }

        llama::LlamaConfig config;
        config.chatModel = settings.chatModel;
        config.embeddingModel = settings.embeddingModel;
        config.embeddingQueryPrefix = settings.embeddingQueryPrefix;
        config.embeddingDocumentPrefix = settings.embeddingDocumentPrefix;
        config.contextSize = settings.contextSize;
        config.gpuLayers = settings.gpuLayers;
        llama::LlamaCppBackend llamaBackend(config);
        std::optional<turn::RecordingBackend> recording;
        if (recordFile) {
            recording.emplace(llamaBackend);
        }
        inference::LlmBackend& backend =
            recording ? static_cast<inference::LlmBackend&>(*recording) : static_cast<inference::LlmBackend&>(llamaBackend);

        std::random_device entropy;
        const std::uint64_t runSeed =
            seed.value_or((static_cast<std::uint64_t>(entropy()) << 32) | static_cast<std::uint64_t>(entropy()));
        RunView view;
        std::vector<turn::ReplayStep> steps;
        {
            turn::Worker worker(settings, backend);
            if (resume) {
                worker.Post(turn::LoadRun{worldFolder, runFile});
            } else {
                worker.Post(turn::StartRun{worldFolder, runFile, runSeed});
            }
            if (!PrintUntilClosing(worker, view)) {
                return 1;
            }

            std::string line;
            while ((std::cout << "\n> " << std::flush) && std::getline(std::cin, line)) {
                line = core::Trim(line);
                if (line.empty()) {
                    continue;
                }
                if (line == "/quit") {
                    break;
                }
                if (line == "/state") {
                    std::cout << context::RenderStateView(view.state);
                    continue;
                }
                turn::ReplayStep step;
                if (line == "/undo") {
                    step.action = turn::ReplayStep::Action::Undo;
                    worker.Post(turn::UndoTurn{});
                } else if (line == "/regen") {
                    step.action = turn::ReplayStep::Action::Regenerate;
                    worker.Post(turn::RegenerateTurn{});
                } else {
                    step.input = line;
                    worker.Post(turn::SubmitInput{line});
                }
                std::cout << '\n';
                if (PrintUntilClosing(worker, view)) {
                    steps.push_back(std::move(step)); // Failed commands change nothing and are not replayed.
                }
            }
        }

        if (recordFile) {
            const core::MemoryMode mode = settings.memoryMode.value_or(core::LoadWorld(worldFolder).defaultMemoryMode);
            std::ofstream out(*recordFile, std::ios::binary);
            out << turn::MakeReplayFixture(core::PathText(worldFolder), runSeed, mode, steps, *recording, view.history,
                                           view.state)
                       .dump(2)
                << '\n';
            if (!out) {
                throw std::runtime_error("cannot write " + core::PathText(*recordFile));
            }
            std::cout << "Wrote " << core::PathText(*recordFile) << '\n';
        }
        return 0;
    } catch (const std::exception& error) {
        std::cerr << "error: " << error.what() << '\n';
        return 1;
    }
}
```
