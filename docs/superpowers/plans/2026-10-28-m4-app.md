# Milestone 4: The App - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the prototype `src/main.cpp` with the SDL3 + Dear ImGui app over `turn::Worker`. It has the spec's six docking windows (Play, State, Context, Turn log, Memory, Settings) and a Runs window for starting and continuing runs, and it launches with F5 from Visual Studio.

**Architecture:**
- **`morpheus_app_model`** (`src/app/model`) holds the app's state and actions. It has no SDL, ImGui or llama.cpp, so the `tests` and `asan` presets build and test it with `ScriptedBackend`.
  - `Catalog`: worlds in `game_projects/`, runs in `saves/<world id>/`, run names and seeds.
  - `SettingsEdit`: the Settings window's values, read from and saved to `settings.json`.
  - `RunModel`: the open run, kept up to date from worker events.
  - `Inspect`: pure helpers for the inspectors (change marks, prompt sections, telemetry rows).
  - `EngineHost`: the backend and worker. It loads models on a background thread and keeps them across a restart that does not need new ones.
  - `AppController`: ties them together. The windows read it and call its actions.
- **`morpheus_app_ui`** (`src/app/ui`) holds the ImGui windows over `AppController`. It needs only `imgui_core` (no backend), so the tests draw every window headless.
- **`morpheus`** (`src/app/main.cpp`, `dev` preset): the SDL3 window, ImGui's SDL3 and SDL_Renderer backends, and the llama.cpp backend factory.
- **Worker events carry memory.** `RunOpened`, `TurnCompleted` and `StateChanged` gain a `MemoryView` (summaries and notes). A new non-closing `MemoryUpdated` reports finished maintenance.
- **Spec:** `docs/superpowers/specs/2026-10-27-morpheus-cpp-architecture-design.md`, "UI (ImGui docking windows)" and "Process and modules".

**Tech Stack:** C++20 with MSVC (VS 2022) and CMake 3.25+. SDL3 3.4.10 and Dear ImGui 1.92.8 (docking branch), plus the engine's dependencies.

**Decisions for this milestone (made with the product owner):**
- **ImGui comes from upstream's docking branch.** `ocornut/imgui` is pinned at tag `v1.92.8-docking`, and its targets are defined in our CMake like SQLite's. It replaces the owner's `cmake-ready-imgui-sdl3` fork, which has no docking. `imgui_core` builds whenever tests or the app are on, so the tests can draw the windows.
- **The Settings window edits and applies.**
  - Apply patches `settings.json`, keeping relative model paths and every key the window does not edit.
  - It checks the result with `core::LoadSettings` before replacing the file, then restarts the engine.
  - The loaded models are kept unless the model paths, embedding prefixes, context size or GPU layers change.
  - The open run reopens on the new worker.
- **Runs are picked in the app.**
  - The Runs window lists the worlds in `game_projects/` and each world's runs in `saves/<world id>/<name>.db`.
  - It offers New run (with a name and an optional seed) and Continue.
  - The app's root folder is its argument, or the current directory. Visual Studio starts it from the repository root, with `morpheus` as the startup project.

**Technical decisions:**
- **Font: Segoe UI from `%WINDIR%\Fonts`.** Narration uses em dashes and curly quotes, which ImGui's built-in font lacks. A missing font file is a startup error with its path.
- **`IM_ASSERT` throws `std::logic_error`** (`src/app/ui/ImGuiConfig.h`, set through `IMGUI_USER_CONFIG`). A UI bug such as an unbalanced Begin/End fails a headless test instead of aborting the test run, and in the app it ends in the startup error box.
- **Layout:**
  - `imgui.ini` is saved in the root folder and gitignored.
  - Without a saved layout, `Ui` docks the windows into a default one with `DockBuilder`: Runs and Settings on the left, Play in the middle, State and Memory on the right, and Turn log and Context below.
- **One command at a time.** Buttons are disabled while a command runs or models load (`AppController::CanPost`). `RunModel::OnPosted` enforces this with `ContractError`.
- **The console window stays.** The app keeps the console subsystem, so llama.cpp's warnings still have somewhere to go.
- **`--frames N`** makes the app exit after N frames. It is a smoke check that the window, font, backends and settings start on this machine, and subagents can run it.
- **Not in M4:**
  - a fallback-summary flag in the store (it needs a schema change);
  - the `SCHEMA_VERSION` bump;
  - editing the budget in the Settings window (shown read-only);
  - a log window.

**Roadmap:** M4 completes v1 as the architecture spec describes it. Visualization and narration TTS have their own specs.

- **Namespaces and targets:**
  - The namespaces are `morpheus::core`, `store`, `inference`, `context`, `llama`, `turn` and `app`.
  - Targets are `morpheus_<module>` (`morpheus_app_model`, `morpheus_app_ui`); the app executable stays `morpheus`.
  - Includes are written as `"module/File.h"` (`"app/model/RunModel.h"`, `"app/ui/Ui.h"`).
- **Error policy:**
  - Engine bugs throw `core::ContractError` (via `MORPHEUS_REQUIRE`).
  - Bad world, settings or saved data throws `core::DataError` or `store::StoreError`, naming the file and field.
  - Model and runtime failures throw `inference::InferenceError`.
  - A turn that cannot run as asked throws `turn::TurnError`; the worker reports it as an `Error` event, which the Play window shows.
  - The UI never swallows an exception. Startup failures end in an error box naming the cause.
- **Module boundaries:**
  - Only `morpheus_llama`, `tools/probe`, `tools/play` and `src/app/main.cpp` link llama.cpp.
  - Only `src/app/main.cpp` includes SDL or the ImGui backends.
  - `morpheus_app_model` includes no ImGui. `morpheus_app_model` and `morpheus_app_ui` build and test under the `tests` and `asan` presets.
- **Threading:**
  - The UI thread owns `AppController`, `RunModel`, `EngineHost` and all ImGui calls.
  - The worker thread is the only user of the backend once the worker exists.
  - `EngineHost`'s loader thread constructs the backend and hands it over under a mutex.

### Task 1: Worker events carry the run's memory

The Memory window shows summaries and notes. Today the worker's events carry neither, and maintenance changes the summaries without any event. This task adds a `MemoryView` to the events that already carry state, and a non-closing `MemoryUpdated` event after maintenance finishes.

**Interfaces:**
- Consumes: `store::RunStore::Notes()`, `Session::Summaries()`.
- Produces:

```cpp
#pragma once

#include <memory>

#include <imgui.h>

namespace morpheus::test {

// An ImGui context with no platform or renderer backend, for drawing windows in tests. The font atlas is built up
// front, as a renderer backend would; frames are laid out but never turned into pixels. Docking is on, like the app.
class HeadlessImGui {
private:
    struct ContextDeleter {
        void operator()(ImGuiContext* pContext) const
        {
            ImGui::DestroyContext(pContext);
        }
    };

    std::unique_ptr<ImGuiContext, ContextDeleter> _pContext = nullptr;

public:
    HeadlessImGui()
        : _pContext(ImGui::CreateContext())
    {
        ImGuiIO& io = ImGui::GetIO();
        io.DisplaySize = ImVec2(1600.0f, 900.0f);
        io.DeltaTime = 1.0f / 60.0f;
        io.IniFilename = nullptr; // No imgui.ini: every test starts from the default layout.
        io.ConfigFlags |= ImGuiConfigFlags_DockingEnable;
        // Without a renderer backend, the atlas must be built before the first frame.
        unsigned char* pPixels = nullptr;
        int width = 0;
        int height = 0;
        io.Fonts->GetTexDataAsRGBA32(&pPixels, &width, &height);
    }
    HeadlessImGui(const HeadlessImGui&) = delete;
    HeadlessImGui& operator=(const HeadlessImGui&) = delete;

    // Draws one frame: `draw` runs between NewFrame and Render.
    template <typename Draw>
    void Frame(Draw&& draw)
    {
        ImGui::NewFrame();
        draw();
        ImGui::Render();
    }
};

} // namespace morpheus::test
```

```cpp
// Dear ImGui's build configuration (IMGUI_USER_CONFIG), set by the imgui_core target for everything that compiles
// or includes ImGui.

#include <stdexcept>
#include <string>

// A failed ImGui assertion is a UI bug (an unbalanced Begin/End, a broken ID stack). Throwing fails loud with the
// expression and location, and lets a headless test report it instead of aborting the test run.
#define IM_ASSERT(expr)                                                                                               \
    ((expr) ? static_cast<void>(0)                                                                                    \
            : throw std::logic_error(std::string("ImGui assertion failed: ") + #expr + " [" + __FILE__ + ":" +       \
                                     std::to_string(__LINE__) + "]"))

#define IMGUI_DISABLE_OBSOLETE_FUNCTIONS
```

```cpp
#include "app/model/Catalog.h"

#include <algorithm>
#include <charconv>
#include <format>
#include <limits>
#include <system_error>
#include <utility>

#include "core/Errors.h"
#include "core/Text.h"
#include "core/World.h"

namespace morpheus::app {

std::vector<WorldEntry> ListWorlds(const std::filesystem::path& projectsDir)
{
    if (!std::filesystem::is_directory(projectsDir)) {
        throw core::DataError(std::format("worlds folder '{}' does not exist", core::PathText(projectsDir)));
    }
    std::vector<WorldEntry> worlds;
    for (const std::filesystem::directory_entry& entry : std::filesystem::directory_iterator(projectsDir)) {
        // Only folders with a world.json are worlds; anything else in the folder is ignored.
        if (!entry.is_directory() || !std::filesystem::exists(entry.path() / "world.json")) {
            continue;
        }
        WorldEntry world;
        world.folder = entry.path();
        try {
            const core::World loaded = core::LoadWorld(entry.path());
            world.id = loaded.id;
            world.title = loaded.title;
        } catch (const core::DataError& error) {
            // Listed with its error rather than hidden: the player sees what to fix.
            world.id = core::PathText(entry.path().filename());
            world.error = error.what();
        }
        worlds.push_back(std::move(world));
    }
    std::sort(worlds.begin(), worlds.end(),
              [](const WorldEntry& a, const WorldEntry& b) { return a.folder.filename() < b.folder.filename(); });
    return worlds;
}

std::vector<RunEntry> ListRuns(const std::filesystem::path& savesDir, std::string_view worldId)
{
    std::vector<RunEntry> runs;
    const std::filesystem::path folder = savesDir / std::string(worldId);
    if (!std::filesystem::is_directory(folder)) {
        return runs; // No run of this world yet.
    }
    for (const std::filesystem::directory_entry& entry : std::filesystem::directory_iterator(folder)) {
        // A run is one .db file; SQLite's side files (.db-wal, .db-shm) have other extensions.
        if (entry.is_regular_file() && entry.path().extension() == ".db") {
            runs.push_back({entry.path(), core::PathText(entry.path().stem()), entry.last_write_time()});
        }
    }
    std::sort(runs.begin(), runs.end(), [](const RunEntry& a, const RunEntry& b) {
        return a.lastWrite != b.lastWrite ? a.lastWrite > b.lastWrite : a.name < b.name;
    });
    return runs;
}

std::filesystem::path RunFile(const std::filesystem::path& savesDir, std::string_view worldId, std::string_view name)
{
    return savesDir / std::string(worldId) / (std::string(name) + ".db");
}

std::string RunNameProblem(const std::filesystem::path& savesDir, std::string_view worldId, std::string_view name)
{
    if (name.empty() || name.size() > RUN_NAME_MAX_CHARS) {
        return std::format("a run name needs 1 to {} characters", RUN_NAME_MAX_CHARS);
    }
    // Only characters that are safe in a file name on every system, so the name is the file name as typed.
    const bool plain = std::all_of(name.begin(), name.end(), [](char c) {
        return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9') || c == '-' || c == '_';
    });
    if (!plain) {
        return "a run name may only use letters, digits, '-' and '_'";
    }
    if (std::filesystem::exists(RunFile(savesDir, worldId, name))) {
        return std::format("a run named '{}' already exists", name);
    }
    return {};
}

std::string DefaultRunName(std::chrono::system_clock::time_point now)
{
    return std::format("run-{:%Y%m%d-%H%M%S}", std::chrono::floor<std::chrono::seconds>(now));
}

SeedInput ParseSeed(std::string_view text)
{
    const std::string trimmed = core::Trim(text);
    if (trimmed.empty()) {
        return {}; // Blank: a random seed.
    }
    // The whole text must be decimal digits that fit 64 bits; from_chars rejects signs for unsigned types.
    std::uint64_t value = 0;
    const char* pEnd = trimmed.data() + trimmed.size();
    const auto [pNext, error] = std::from_chars(trimmed.data(), pEnd, value);
    if (error != std::errc() || pNext != pEnd) {
        return {std::nullopt, std::format("'{}' is not a seed: use a whole number from 0 to {}", trimmed,
                                          std::numeric_limits<std::uint64_t>::max())};
    }
    return {value, {}};
}

std::string LocalTimeText(std::filesystem::file_time_type time)
{
    const auto system = std::chrono::clock_cast<std::chrono::system_clock>(time);
    const std::chrono::zoned_time local(std::chrono::current_zone(), std::chrono::floor<std::chrono::minutes>(system));
    return std::format("{:%Y-%m-%d %H:%M}", local);
}

} // namespace morpheus::app
```

```cpp
#include <nlohmann/json.hpp>
```

```cpp
#include "core/Text.h"

namespace {

// The settings file as JSON, keeping its key order. Throws DataError naming the file when it cannot be read or
// parsed.
nlohmann::ordered_json ReadJson(const std::filesystem::path& file)
{
    std::ifstream stream(file, std::ios::binary);
    if (!stream) {
        throw core::DataError(std::format("cannot read {}", core::PathText(file)));
    }
    try {
        return nlohmann::ordered_json::parse(stream);
    } catch (const nlohmann::json::exception& error) {
        throw core::DataError(std::format("{}: {}", core::PathText(file), error.what()));
    }
}

} // namespace

SettingsEdit ReadSettingsEdit(const std::filesystem::path& file)
{
    const nlohmann::ordered_json json = ReadJson(file);
    try {
        // One call type's sampling block.
        auto sampling = [](const nlohmann::ordered_json& block) {
            return core::SamplingSettings{block.at("temperature").get<double>(), block.at("top_k").get<int>(),
                                          block.at("top_p").get<double>()};
        };
        SettingsEdit edit;
        edit.chatModel = json.at("chat_model").get<std::string>();
        edit.embeddingModel = json.at("embedding_model").get<std::string>();
        edit.contextSize = json.at("context_size").get<int>();
        edit.gpuLayers = json.at("gpu_layers").get<int>();
        edit.resolveSampling = sampling(json.at("sampling").at("resolve"));
        edit.narrateSampling = sampling(json.at("sampling").at("narrate"));
        if (json.contains("memory_mode")) {
            edit.memoryMode = core::ParseMemoryMode(json.at("memory_mode").get<std::string>());
            if (!edit.memoryMode) {
                throw core::DataError(
                    std::format("{}: 'memory_mode' must be 'engine' or 'assisted'", core::PathText(file)));
            }
        }
        return edit;
    } catch (const nlohmann::json::exception& error) {
        // A missing key or a value of the wrong type.
        throw core::DataError(std::format("{}: {}", core::PathText(file), error.what()));
    }
}

core::Settings SaveSettingsEdit(const std::filesystem::path& file, const SettingsEdit& edit)
{
    // Patch the file's own JSON, so keys the window does not edit, their order and relative paths stay as written.
    nlohmann::ordered_json json = ReadJson(file);
    auto samplingJson = [](const core::SamplingSettings& sampling) {
        return nlohmann::ordered_json{
            {"temperature", sampling.temperature}, {"top_k", sampling.topK}, {"top_p", sampling.topP}};
    };
    json["chat_model"] = edit.chatModel;
    json["embedding_model"] = edit.embeddingModel;
    json["context_size"] = edit.contextSize;
    json["gpu_layers"] = edit.gpuLayers;
    json["sampling"]["resolve"] = samplingJson(edit.resolveSampling);
    json["sampling"]["narrate"] = samplingJson(edit.narrateSampling);
    if (edit.memoryMode) {
        json["memory_mode"] = *edit.memoryMode == core::MemoryMode::Engine ? "engine" : "assisted";
    } else {
        json.erase("memory_mode");
    }

    // Check the result with the real loader before replacing anything. The check file sits beside the settings
    // file, so relative model paths resolve the same way.
    std::filesystem::path checkFile = file;
    checkFile += ".new";
    {
        std::ofstream stream(checkFile, std::ios::binary | std::ios::trunc);
        stream << json.dump(2) << '\n';
        stream.close();
        if (stream.fail()) {
            throw core::DataError(std::format("cannot write {}", core::PathText(checkFile)));
        }
    }
    core::Settings settings;
    try {
        settings = core::LoadSettings(checkFile);
    } catch (const core::DataError&) {
        // The settings error is what the player needs; a check file that will not delete must not replace it.
        std::error_code ignored;
        std::filesystem::remove(checkFile, ignored);
        throw;
    }
    std::filesystem::rename(checkFile, file); // Replaces the settings file in one step.
    return settings;
}

} // namespace morpheus::app
```

```cpp
#include "app/model/RunModel.h"

#include <utility>
#include <variant>

#include "core/Errors.h"

namespace morpheus::app {

void RunModel::OnPosted(const turn::Command& command)
{
    MORPHEUS_REQUIRE(_busy == Busy::None, "RunModel: a command is already running");
    _lastError.clear();
    if (std::holds_alternative<turn::StartRun>(command) || std::holds_alternative<turn::LoadRun>(command)) {
        _busy = Busy::Opening;
        return;
    }
    MORPHEUS_REQUIRE(_open, "RunModel: a turn command needs an open run");
    if (const auto* pInput = std::get_if<turn::SubmitInput>(&command)) {
        _busy = Busy::Turn;
        _pending = PendingTurn{pInput->text};
        return;
    }
    MORPHEUS_REQUIRE(!_history.empty(), "RunModel: undo and regenerate need a committed turn");
    if (std::holds_alternative<turn::RegenerateTurn>(command)) {
        _busy = Busy::Regenerate;
        _pending = PendingTurn{_history.back().input}; // The same input, played again.
        return;
    }
    _busy = Busy::Undo;
}

void RunModel::Apply(const turn::Event& event)
{
    // Progress of the running turn.
    if (const auto* pResolved = std::get_if<turn::TurnResolved>(&event)) {
        MORPHEUS_REQUIRE(_pending.has_value(), "RunModel: TurnResolved with no turn running");
        _pending->resolved = pResolved->record;
        return;
    }
    if (const auto* pPiece = std::get_if<turn::TokenStreamed>(&event)) {
        MORPHEUS_REQUIRE(_pending.has_value(), "RunModel: TokenStreamed with no turn running");
        _pending->narration += pPiece->piece;
        return;
    }
    // Maintenance reports, between commands.
    if (const auto* pUpdated = std::get_if<turn::MemoryUpdated>(&event)) {
        _memory = pUpdated->memory;
        _maintenanceError.clear();
        return;
    }
    if (const auto* pFailed = std::get_if<turn::MaintenanceFailed>(&event)) {
        _maintenanceError = pFailed->message;
        return;
    }

    // Every other event closes the running command.
    MORPHEUS_REQUIRE(_busy != Busy::None, "RunModel: a closing event with no command running");
    const Busy finished = _busy;
    _busy = Busy::None;
    std::optional<PendingTurn> pending = std::move(_pending);
    _pending.reset();

    if (const auto* pOpened = std::get_if<turn::RunOpened>(&event)) {
        _open = true;
        _meta = pOpened->meta;
        _worldChanged = pOpened->worldChanged;
        _history = pOpened->history;
        _state = pOpened->state;
        _memory = pOpened->memory;
        _lastAssembly.reset(); // The prompt shows again once a turn is played.
        _maintenanceError.clear();
        return;
    }
    if (const auto* pCompleted = std::get_if<turn::TurnCompleted>(&event)) {
        if (finished == Busy::Regenerate) {
            MORPHEUS_REQUIRE(!_history.empty() && _history.back().number == pCompleted->record.number,
                             "RunModel: a regenerated turn must replace the latest turn");
            _history.back() = pCompleted->record;
        } else {
            MORPHEUS_REQUIRE(finished == Busy::Turn &&
                                 pCompleted->record.number == static_cast<int>(_history.size()) + 1,
                             "RunModel: a new turn must follow the latest turn");
            _history.push_back(pCompleted->record);
        }
        _state = pCompleted->state;
        _memory = pCompleted->memory;
        _lastAssembly = pCompleted->assembly;
        return;
    }
    if (const auto* pChanged = std::get_if<turn::StateChanged>(&event)) {
        _history = pChanged->history;
        _state = pChanged->state;
        _memory = pChanged->memory;
        _lastAssembly.reset(); // It was the prompt of a turn that is gone.
        return;
    }

    // TurnCancelled or Error: nothing was committed. A submitted input goes back to the input box.
    if (pending && finished == Busy::Turn) {
        _restoredInput = std::move(pending->input);
    }
    if (const auto* pError = std::get_if<turn::Error>(&event)) {
        if (finished == Busy::Opening) {
            Close(); // A failed StartRun or LoadRun has already closed the previous run.
        }
        _lastError = pError->message;
    }
}

void RunModel::Close()
{
    *this = RunModel();
}

bool RunModel::Open() const
{
    return _open;
}

const store::RunMeta& RunModel::Meta() const
{
    return _meta;
}

bool RunModel::WorldChanged() const
{
    return _worldChanged;
}

const std::vector<core::TurnRecord>& RunModel::History() const
{
    return _history;
}

std::span<const core::TurnRecord> RunModel::TranscriptTurns() const
{
    // OnPosted guarantees a turn to hide while regenerating.
    const std::size_t shown = _busy == Busy::Regenerate ? _history.size() - 1 : _history.size();
    return std::span<const core::TurnRecord>(_history.data(), shown);
}

{
    return _state;
}

{
    return _memory;
}

    return _lastAssembly;

    return _busy;
```

```cpp
    int generated = 0;
```

```cpp
ChangeMark MarkFor(std::string_view path, const std::vector<core::AppliedChange>& applied)
{
    // Whether `inner` is `outer` or lies inside it, nesting on '.' boundaries ("npc_10" is not inside "npc_1").
    auto within = [](std::string_view inner, std::string_view outer) {
        return inner.substr(0, outer.size()) == outer && (inner.size() == outer.size() || inner[outer.size()] == '.');
    };
    ChangeMark mark = ChangeMark::None;
    for (const core::AppliedChange& change : applied) {
        if (within(path, change.change.path)) {
            return ChangeMark::Changed;
        }
        if (within(change.change.path, path)) {
            mark = ChangeMark::Contains; // Keep looking: another change may target this node itself.
        }
    }
    return mark;
}

std::vector<PromptSection> PromptSections(const inference::Prompt& prompt)
{
    std::vector<PromptSection> sections;
    for (std::size_t i = 0; i < prompt.messages.size(); ++i) {
        const inference::Message& message = prompt.messages[i];
        const char* layer = i == 0                   ? "L0 engine rules, L1 world, L2 summary"
                            : i < prompt.stableCount ? "L3 transcript"
                                                     : "tail (T1-T4)";
        sections.push_back({std::format("#{} {} - {}", i, inference::RoleName(message.role), layer), message.content});
    }
    return sections;
}

std::string RawPrompt(const inference::Prompt& prompt)
{
    std::string text;
    for (const inference::Message& message : prompt.messages) {
        text += std::format("=== {} ===\n{}\n", inference::RoleName(message.role), message.content);
    }
    return text;
}

std::optional<CallStats> CallStatsOf(const nlohmann::json& timings, std::string_view call)
{
    const std::string key(call);
    if (!timings.is_object() || !timings.contains(key)) {
        return std::nullopt;
    }
    try {
        const nlohmann::json& numbers = timings.at(key);
        return CallStats{numbers.at("prompt_tokens").get<int>(), numbers.at("reused").get<int>(),
                         numbers.at("evaluated").get<int>(),     numbers.at("generated").get<int>(),
                         numbers.at("prompt_ms").get<double>(),  numbers.at("generate_ms").get<double>(),
                         numbers.at("stopped_at_limit").get<bool>()};
    } catch (const nlohmann::json::exception& error) {
        throw core::DataError(std::format("turn telemetry '{}': {}", key, error.what()));
    }
}

std::vector<RetrievalRow> RetrievalRows(const nlohmann::json& timings, const std::vector<core::TurnRecord>& history,
                                        const std::vector<core::Note>& notes)
{
    std::vector<RetrievalRow> rows;
    if (!timings.is_object() || !timings.contains("retrieval")) {
        return rows;
    }
    // A decimal number from a ref, or nullopt.
    auto number = [](std::string_view text) -> std::optional<int> {
        int value = 0;
        const auto [pNext, error] = std::from_chars(text.data(), text.data() + text.size(), value);
        if (error != std::errc() || pNext != text.data() + text.size()) {
            return std::nullopt;
        }
        return value;
    };
    try {
        for (const nlohmann::json& hit : timings.at("retrieval")) {
            RetrievalRow row;
            row.source = hit.at("source").get<std::string>();
            row.ref = hit.at("ref").get<std::string>();
            row.score = hit.at("score").get<double>();
            const std::string missing =
                std::format("turn telemetry names {} '{}', which the run does not hold", row.source, row.ref);
            if (row.source == "history") {
                // The ref is the turn number.
                const std::optional<int> turn = number(row.ref);
                const auto found = std::find_if(history.begin(), history.end(), [&](const core::TurnRecord& record) {
                    return turn && record.number == *turn;
                });
                if (found == history.end()) {
                    throw core::DataError(missing);
                }
                row.text = found->input;
            } else if (row.source == "notes") {
                // The ref is "<turn>.<index>": the index-th note that turn wrote.
                const std::size_t dot = row.ref.find('.');
                const std::optional<int> turn =
                    dot == std::string::npos ? std::nullopt : number(std::string_view(row.ref).substr(0, dot));
                const std::optional<int> index =
                    dot == std::string::npos ? std::nullopt : number(std::string_view(row.ref).substr(dot + 1));
                int seen = 0;
                bool found = false;
                for (const core::Note& note : notes) {
                    if (turn && index && note.turn == *turn && seen++ == *index) {
                        row.text = note.text;
                        found = true;
                        break;
                    }
                }
                if (!found) {
                    throw core::DataError(missing);
                }
            } else {
                row.text = row.ref; // A lore hit's ref is its subject.
            }
            rows.push_back(std::move(row));
        }
    } catch (const nlohmann::json::exception& error) {
        throw core::DataError(std::format("turn telemetry 'retrieval': {}", error.what()));
    }
    return rows;
}

std::string CheckText(const core::CheckOutcome& check)
{
    std::string rolls;
    for (const int roll : check.result.rolls) {
        rolls += (rolls.empty() ? "" : " + ") + std::to_string(roll);
    }
    const int stat = check.result.statValue;
    const std::string statPart = stat == 0 ? "" : std::format(" {} {}", stat < 0 ? '-' : '+', std::abs(stat));
    return std::format("{} vs {}: rolled {}{} = {} against {}, {}", check.stat, check.difficulty, rolls, statPart,
                       check.result.total, check.result.target, check.result.success ? "success" : "failure");
}

} // namespace morpheus::app
```

```cpp
#include <functional>
#include <memory>
#include <mutex>
#include <string>

#include "core/Settings.h"
#include "inference/Llm.h"
#include "turn/Worker.h"

namespace morpheus::app {

// Owns the backend and the worker (UI thread only). Models load on a background thread, so the UI keeps drawing.
// A restart that changes no backend setting keeps the loaded backend and replaces only the worker.
class EngineHost {
public:
    // Makes the backend for `settings`. It may take seconds (it loads models) and may throw.
    using BackendFactory = std::function<std::unique_ptr<inference::LlmBackend>(const core::Settings&)>;

    enum class Status { Stopped, Loading, Ready, Failed };

private:
    BackendFactory _factory = {};
    core::Settings _settings = {};
    Status _status = Status::Stopped;
    std::string _failure = {};
    std::unique_ptr<inference::LlmBackend> _pBackend = nullptr;
    std::unique_ptr<turn::Worker> _pWorker = nullptr; // After the backend, so it is destroyed first.
    std::mutex _loadMutex = {};
    std::unique_ptr<inference::LlmBackend> _pLoaded = nullptr; // The loader's result, under _loadMutex.
    std::string _loadError = {};                               // The loader's failure, under _loadMutex.
    bool _loadDone = false;                                    // Under _loadMutex.
    std::jthread _loader = {}; // Last: joined first on destruction, before the members it writes.

public:
    explicit EngineHost(BackendFactory factory);

    // Starts the engine with `settings`. The running worker stops first, cancelling its command and closing its

    void Poll();

    const std::string& Failure() const;             // Why the last load failed (Failed).
    const core::Settings& CurrentSettings() const;  // The settings of the last Start.
```

```cpp
#include <exception>

namespace morpheus::app {

EngineHost::EngineHost(BackendFactory factory)
    : _factory(std::move(factory))
{
}

void EngineHost::Start(core::Settings settings)
{
    MORPHEUS_REQUIRE(_status != Status::Loading, "EngineHost: Start while models load");
    // Whether the loaded backend was made for the same models, prefixes and context.
    const bool sameBackend = _pBackend && settings.chatModel == _settings.chatModel &&
                             settings.embeddingModel == _settings.embeddingModel &&
                             settings.embeddingQueryPrefix == _settings.embeddingQueryPrefix &&
                             settings.embeddingDocumentPrefix == _settings.embeddingDocumentPrefix &&
                             settings.contextSize == _settings.contextSize && settings.gpuLayers == _settings.gpuLayers;
    _pWorker.reset(); // Cancels its command and joins it; the run it had open closes.
    _settings = std::move(settings);
    _failure.clear();
    if (sameBackend) {
        _pWorker = std::make_unique<turn::Worker>(_settings, *_pBackend);
        _status = Status::Ready;
        return;
    }

    // Free the old models before loading new ones: both may not fit in GPU memory.
    _pBackend.reset();
    {
        std::scoped_lock lock(_loadMutex);
        _pLoaded.reset();
        _loadError.clear();
        _loadDone = false;
    }
    _status = Status::Loading;
    // The loader only calls the factory and hands its result over under the lock; Poll takes it.
    _loader = std::jthread([this, settings = _settings] {
        std::unique_ptr<inference::LlmBackend> pLoaded = nullptr;
        std::string error;
        try {
            pLoaded = _factory(settings);
            MORPHEUS_REQUIRE(pLoaded != nullptr, "EngineHost: the backend factory returned no backend");
        } catch (const std::exception& failure) {
            error = failure.what();
        }
        std::scoped_lock lock(_loadMutex);
        _pLoaded = std::move(pLoaded);
        _loadError = std::move(error);
        _loadDone = true;
    });
}

void EngineHost::Poll()
{
    if (_status != Status::Loading) {
        return;
    }
    std::unique_ptr<inference::LlmBackend> pLoaded = nullptr;
    std::string error;
    {
        std::scoped_lock lock(_loadMutex);
        if (!_loadDone) {
            return; // Still loading.
        }
        pLoaded = std::move(_pLoaded);
        error = std::move(_loadError);
    }
    _loader.join(); // The loader has finished its work: this returns at once.
    if (!pLoaded) {
        _status = Status::Failed;
        _failure = std::move(error);
        return;
    }
    _pBackend = std::move(pLoaded);
    _pWorker = std::make_unique<turn::Worker>(_settings, *_pBackend);
    _status = Status::Ready;
}

EngineHost::Status EngineHost::CurrentStatus() const
{
    return _status;
}

const std::string& EngineHost::Failure() const
{
    return _failure;
}

const core::Settings& EngineHost::CurrentSettings() const
{
    return _settings;
}

turn::Worker* EngineHost::ActiveWorker()
{
    return _status == Status::Ready ? _pWorker.get() : nullptr;
}
```

```cpp
inline app::EngineHost::BackendFactory ScriptedFactory(ScriptedBackend::Responder responder,

    return [responder, pieceDelay](const core::Settings& settings) -> std::unique_ptr<inference::LlmBackend> {

        pBackend->SetPieceDelay(pieceDelay);
        return pBackend;
    };
}

// Runs the controller's frames until `done` holds. Fails the test after 10 s.
template <typename Done>
void PumpUntil(app::AppController& controller, Done done)
{
    const auto deadline = std::chrono::steady_clock::now() + std::chrono::seconds(10);
    for (;;) {
        controller.Frame();
        if (done()) {
            return;
        }
        REQUIRE(std::chrono::steady_clock::now() < deadline);
        std::this_thread::sleep_for(std::chrono::milliseconds(1));
    }
}
```

```cpp
#include "app/model/AppController.h"

#include <random>
#include <utility>
#include <variant>

#include "core/Errors.h"

namespace morpheus::app {

AppPaths AppController::PathsUnder(const std::filesystem::path& root)
{
    return {root / "settings.json", root / "game_projects", root / "saves"};
}

AppController::AppController(AppPaths paths, EngineHost::BackendFactory factory)
    : _paths(std::move(paths))
    , _engine(std::move(factory))
{
    // Invalid settings stop the app here, naming the file and key.
    _engine.Start(core::LoadSettings(_paths.settingsFile));
    _worlds = ListWorlds(_paths.projectsDir);
}

void AppController::Frame()
{
    _engine.Poll();
    turn::Worker* pWorker = _engine.ActiveWorker();
    if (!pWorker) {
        return; // Loading, failed or stopped: no events to take.
    }
    // A run that was open before a settings restart reopens on the new worker.
    if (_reopen && _run.CurrentBusy() == RunModel::Busy::None) {
        turn::LoadRun reopen = std::move(*_reopen);
        _reopen.reset();
        _opening = reopen;
        Post(std::move(reopen));
    }
    for (const turn::Event& event : pWorker->PollEvents()) {
        _run.Apply(event);
        // Keep track of which files the open run lives in.
        if (!_opening) {
            continue;
        }
        if (std::holds_alternative<turn::RunOpened>(event)) {
            _openRun = std::move(_opening);
            _opening.reset();
        } else if (std::holds_alternative<turn::Error>(event)) {
            _openRun.reset(); // A failed open has already closed the previous run.
            _opening.reset();
        } else if (std::holds_alternative<turn::TurnCancelled>(event)) {
            _opening.reset(); // Cancelled before it ran: the previous run stays open.
        }
    }
}

{
    return _paths;
}

{
    return _engine;
}

           !_reopen;

void AppController::NewRun(const WorldEntry& world, std::string_view name, std::optional<std::uint64_t> seed)
{
    MORPHEUS_REQUIRE(CanPost(), "AppController: NewRun while the UI cannot post");
    MORPHEUS_REQUIRE(world.error.empty() && RunNameProblem(_paths.savesDir, world.id, name).empty(),
                     "AppController: NewRun needs a loadable world and a usable run name");
    if (!seed) {
        std::random_device entropy;
        seed = (static_cast<std::uint64_t>(entropy()) << 32) | static_cast<std::uint64_t>(entropy());
    }
    const std::filesystem::path file = RunFile(_paths.savesDir, world.id, name);
    _opening = turn::LoadRun{world.folder, file};
    Post(turn::StartRun{world.folder, file, *seed});
}

void AppController::ContinueRun(const WorldEntry& world, const RunEntry& run)
{
    MORPHEUS_REQUIRE(CanPost(), "AppController: ContinueRun while the UI cannot post");
    _opening = turn::LoadRun{world.folder, run.file};
    Post(turn::LoadRun{world.folder, run.file});
}

void AppController::Submit(std::string text)
{

    Post(turn::SubmitInput{std::move(text)});
}

void AppController::Undo()
{
    MORPHEUS_REQUIRE(CanPost(), "AppController: Undo while the UI cannot post");
    Post(turn::UndoTurn{});
}

void AppController::Regenerate()
{
    MORPHEUS_REQUIRE(CanPost(), "AppController: Regenerate while the UI cannot post");
    Post(turn::RegenerateTurn{});
}

void AppController::Cancel()
{
    turn::Worker* pWorker = _engine.ActiveWorker();
    if (pWorker && _run.CurrentBusy() != RunModel::Busy::None) {
        pWorker->Cancel(); // The command still closes with its own event, which Frame applies.
    }
}

std::string AppController::ApplySettings(const SettingsEdit& edit)
{
    MORPHEUS_REQUIRE(CanApplySettings(), "AppController: ApplySettings while a command runs or models load");
    core::Settings settings;
    try {
        settings = SaveSettingsEdit(_paths.settingsFile, edit);
    } catch (const core::DataError& error) {
        return error.what(); // The window shows it; the file and the engine are unchanged.
    }
    // The restart closes the open run with the old worker; it reopens on the new one. A reopen still waiting from an
    // earlier restart (whose engine failed to load) is kept.
    if (_openRun) {
        _reopen = std::move(_openRun);
        _openRun.reset();
    }
    _run.Close();
    _engine.Start(std::move(settings));
    return {};
}

std::optional<std::string> AppController::TakeRestoredInput()
{
    return _run.TakeRestoredInput();
}

void AppController::Post(turn::Command command)
{
    turn::Worker* pWorker = _engine.ActiveWorker();
    MORPHEUS_REQUIRE(pWorker != nullptr, "AppController: no worker to post to");
    _run.OnPosted(command);
    pWorker->Post(std::move(command));
}
```

```cpp
void TextWrappedColored(const ImVec4& color, std::string_view text)
{
    ImGui::PushStyleColor(ImGuiCol_Text, color);
    ImGui::PushTextWrapPos(0.0f);
    ImGui::TextUnformatted(text.data(), text.data() + text.size());
    ImGui::PopTextWrapPos();
    ImGui::PopStyleColor();
}

void Ui::Draw(AppController& controller)
{
    ImGuiViewport* pViewport = ImGui::GetMainViewport();

    // The status bar along the bottom: what the engine and the run are doing. It is drawn before the dock space,
    // which then fills the rest of the viewport.
    std::string status;
    switch (controller.Engine().CurrentStatus()) {
    case EngineHost::Status::Stopped:
        status = "Engine stopped";
        break;
    case EngineHost::Status::Loading:
        status = "Loading models...";
        break;
    case EngineHost::Status::Failed:
        status = "Engine failed: " + controller.Engine().Failure() + " (fix it in Settings and apply)";
        break;
    case EngineHost::Status::Ready:
        switch (controller.Run().CurrentBusy()) {
        case RunModel::Busy::None:
            status = controller.Run().Open() ? std::format("Ready - {}, {} turns", controller.Run().Meta().worldId,
                                                           controller.Run().History().size())
                                             : std::string("Ready - no run open");
            break;
        case RunModel::Busy::Opening:
            status = "Opening the run...";
            break;
        case RunModel::Busy::Turn:
            status = "Playing the turn...";
            break;
        case RunModel::Busy::Regenerate:
            status = "Playing the turn again...";
            break;
        case RunModel::Busy::Undo:
            status = "Undoing the turn...";
            break;
        }
        break;
    }
    const ImGuiWindowFlags barFlags =
        ImGuiWindowFlags_NoScrollbar | ImGuiWindowFlags_NoSavedSettings | ImGuiWindowFlags_MenuBar;
    if (ImGui::BeginViewportSideBar("##status", pViewport, ImGuiDir_Down, ImGui::GetFrameHeight(), barFlags)) {
        if (ImGui::BeginMenuBar()) {
            ImGui::TextUnformatted(status.c_str());
            ImGui::EndMenuBar();
        }
    }
    ImGui::End();

    // The dock space. Without a saved layout (first launch, or imgui.ini deleted), the windows are docked into the
    // default one: runs and settings on the left, the story in the middle, state and memory on the right, and the
    // turn log and context below the story.
    const ImGuiID dockspaceId = ImGui::GetID("MainDockSpace");
    if (ImGui::DockBuilderGetNode(dockspaceId) == nullptr) {
        ImGui::DockBuilderAddNode(dockspaceId, ImGuiDockNodeFlags_DockSpace);
        ImGui::DockBuilderSetNodeSize(dockspaceId, pViewport->WorkSize);
        ImGuiID center = dockspaceId;
        const ImGuiID left = ImGui::DockBuilderSplitNode(center, ImGuiDir_Left, 0.22f, nullptr, &center);
        const ImGuiID right = ImGui::DockBuilderSplitNode(center, ImGuiDir_Right, 0.32f, nullptr, &center);
        const ImGuiID bottom = ImGui::DockBuilderSplitNode(center, ImGuiDir_Down, 0.30f, nullptr, &center);
        ImGui::DockBuilderDockWindow(RUNS_WINDOW, left);
        ImGui::DockBuilderDockWindow(SETTINGS_WINDOW, left);
        ImGui::DockBuilderDockWindow(PLAY_WINDOW, center);
        ImGui::DockBuilderDockWindow(STATE_WINDOW, right);
        ImGui::DockBuilderDockWindow(MEMORY_WINDOW, right);
        ImGui::DockBuilderDockWindow(TURN_LOG_WINDOW, bottom);
        ImGui::DockBuilderDockWindow(CONTEXT_WINDOW, bottom);
        ImGui::DockBuilderFinish(dockspaceId);
    }
    ImGui::DockSpaceOverViewport(dockspaceId, pViewport);

    _runs.Draw(controller);
    _play.Draw(controller);
}
```

```cpp
void RunsWindow::Draw(AppController& controller)
{
    if (ImGui::Begin(RUNS_WINDOW)) {
        // The open run.
        if (const std::optional<turn::LoadRun>& open = controller.OpenRun()) {
            ImGui::Text("Open: %s / %s", controller.Run().Meta().worldId.c_str(),
                        core::PathText(open->runFile.stem()).c_str());
        } else {
            ImGui::TextDisabled("No run open");
        }

        // The worlds. Refresh lists them again after world files were added or edited.
        ImGui::SeparatorText("Worlds");
        if (ImGui::SmallButton("Refresh")) {
            controller.RefreshWorlds();
            _selectedWorld = 0;
            _suggestName = true;
            _runsKey.clear();
        }
        const std::vector<WorldEntry>& worlds = controller.Worlds();
        if (worlds.empty()) {
            ImGui::TextDisabled("No worlds in %s", core::PathText(controller.Paths().projectsDir).c_str());
        }
        for (std::size_t i = 0; i < worlds.size(); ++i) {
            const WorldEntry& world = worlds[i];
            ImGui::PushID(static_cast<int>(i));
            if (!world.error.empty()) {
                TextWrappedColored(ERROR_COLOR, std::format("{}: {}", world.id, world.error)); // Not playable.
            } else if (ImGui::Selectable(std::format("{} ({})", world.title, world.id).c_str(), _selectedWorld == i)) {
                if (_selectedWorld != i) {
                    _selectedWorld = i;
                    _suggestName = true;
                }
            }
            ImGui::PopID();
        }
        if (_selectedWorld >= worlds.size() || !worlds[_selectedWorld].error.empty()) {
            ImGui::TextDisabled("Select a world to start or continue a run.");
        } else {
            const WorldEntry& world = worlds[_selectedWorld];

            // A new run: a name (suggested from the clock) and an optional seed.
            ImGui::SeparatorText("New run");
            if (_suggestName) {
                _runName = DefaultRunName(std::chrono::system_clock::now());
                _suggestName = false;
            }
            ImGui::InputText("Name", &_runName);
            ImGui::InputTextWithHint("Seed", "random", &_seedText);
            const std::string nameProblem = RunNameProblem(controller.Paths().savesDir, world.id, _runName);
            const SeedInput seed = ParseSeed(_seedText);
            const std::string problem = nameProblem.empty() ? seed.problem : nameProblem;
            if (!problem.empty()) {
                TextWrappedColored(ERROR_COLOR, problem);
            }
            ImGui::BeginDisabled(!controller.CanPost() || !problem.empty());
            if (ImGui::Button("Start")) {
                controller.NewRun(world, _runName, seed.seed);
                _suggestName = true;
                _seedText.clear();
            }
            ImGui::EndDisabled();

            // The world's saved runs. They are listed again when the world, the open run or its turn count changes:
            // a turn writes its run's file, which moves it to the top.
            const std::string runsKey =
                std::format("{}|{}|{}", world.id,
                            controller.OpenRun() ? core::PathText(controller.OpenRun()->runFile) : std::string(),
                            controller.Run().History().size());
            if (runsKey != _runsKey) {
                _runs = ListRuns(controller.Paths().savesDir, world.id);
                _runsKey = runsKey;
            }
            ImGui::SeparatorText("Saved runs");
            if (_runs.empty()) {
                ImGui::TextDisabled("No runs yet.");
            }
            for (const RunEntry& run : _runs) {
                ImGui::PushID(run.name.c_str());
                ImGui::BeginDisabled(!controller.CanPost());
                if (ImGui::SmallButton("Continue")) {
                    controller.ContinueRun(world, run);
                }
                ImGui::EndDisabled();
                ImGui::SameLine();
                ImGui::TextUnformatted(run.name.c_str());
                ImGui::SameLine();
                ImGui::TextDisabled("%s", LocalTimeText(run.lastWrite).c_str());
                ImGui::PopID();
            }
        }
    }
    ImGui::End();
}
```

```cpp
#include "app/ui/Windows.h"

#include <cfloat>
#include <optional>
#include <string>
#include <utility>

#include <imgui.h>
#include <imgui_stdlib.h>

#include "context/Transcript.h"
#include "core/Text.h"

namespace morpheus::app {

namespace {

constexpr float INPUT_LINES = 4.0f; // Height of the input box, in lines of text.

} // namespace

void PlayWindow::Draw(AppController& controller)
{
    if (ImGui::Begin(PLAY_WINDOW)) {
        const RunModel& run = controller.Run();
        if (!run.Open()) {
            ImGui::TextDisabled("No run open: start or continue one in the Runs window.");
            if (!run.LastError().empty()) {
                TextWrappedColored(ERROR_COLOR, run.LastError());
            }
        } else {
            if (run.WorldChanged()) {
                TextWrappedColored(WARNING_COLOR, "The world's files changed since this run started.");
            }

            // One turn as the transcript shows it: the input, the mechanics line (rolls and changes), the narration.
            auto drawTurn = [](const std::string& input, const std::string& mechanics, const std::string& narration) {
                TextWrappedColored(INPUT_COLOR, "> " + input);
                if (!mechanics.empty()) {
                    TextWrappedColored(MECHANICS_COLOR, mechanics);
                }
                ImGui::TextWrapped("%s", narration.c_str());
                ImGui::Spacing();
            };

            // The transcript fills the window above the input box and the buttons.
            const ImGuiStyle& style = ImGui::GetStyle();
            const float inputHeight = ImGui::GetTextLineHeight() * INPUT_LINES + style.FramePadding.y * 2.0f;
            const float footerHeight = inputHeight + style.ItemSpacing.y + ImGui::GetFrameHeightWithSpacing();
            if (ImGui::BeginChild("transcript", ImVec2(0.0f, -footerHeight), ImGuiChildFlags_Borders)) {
                // Follow new text while the view is at the bottom; scrolling up to read stops following.
                const bool atBottom = ImGui::GetScrollY() >= ImGui::GetScrollMaxY() - 1.0f;
                for (const core::TurnRecord& turn : run.TranscriptTurns()) {
                    drawTurn(turn.input, context::RenderMechanicsLine(turn), turn.narration);
                }
                if (const std::optional<RunModel::PendingTurn>& pending = run.Pending()) {
                    const std::string mechanics = pending->resolved ? context::RenderMechanicsLine(*pending->resolved)
                                                                    : std::string("(resolving...)");
                    drawTurn(pending->input, mechanics,
                             pending->narration.empty() ? std::string("...") : pending->narration);
                }
                if (!run.LastError().empty()) {
                    TextWrappedColored(ERROR_COLOR, run.LastError());
                }
                if (!run.MaintenanceError().empty()) {
                    TextWrappedColored(WARNING_COLOR, "Memory upkeep failed: " + run.MaintenanceError());
                }
                if (atBottom) {
                    ImGui::SetScrollHereY(1.0f);
                }
            }
            ImGui::EndChild();

            // The input box: Enter plays the turn, Ctrl+Enter starts a new line. A cancelled or failed turn's input
            // comes back to it when it is empty.
            if (std::optional<std::string> restored = controller.TakeRestoredInput(); restored && _input.empty()) {
                _input = std::move(*restored);
            }
            const bool canPost = controller.CanPost();
            if (canPost && !_couldPost) {
                ImGui::SetKeyboardFocusHere(); // Ready again: type the next action straight away.
            }
            _couldPost = canPost;
            ImGui::BeginDisabled(!canPost);
            const bool entered =
                ImGui::InputTextMultiline("##input", &_input, ImVec2(-FLT_MIN, inputHeight),
                                          ImGuiInputTextFlags_EnterReturnsTrue | ImGuiInputTextFlags_CtrlEnterForNewLine);
            const bool played = ImGui::Button("Play");
            ImGui::SameLine();
            ImGui::BeginDisabled(run.History().empty());
            const bool undo = ImGui::Button("Undo");
            ImGui::SameLine();
            const bool regenerate = ImGui::Button("Regenerate");
            ImGui::EndDisabled();
            ImGui::EndDisabled();
            ImGui::SameLine();
            const bool turnRunning =
                run.CurrentBusy() == RunModel::Busy::Turn || run.CurrentBusy() == RunModel::Busy::Regenerate;
            ImGui::BeginDisabled(!turnRunning);
            const bool cancel = ImGui::Button("Cancel");
            ImGui::EndDisabled();

            // Act after drawing, so one frame posts at most one command.
            if (cancel) {
                controller.Cancel();
            } else if (undo) {
                controller.Undo();
            } else if (regenerate) {
                controller.Regenerate();
            } else if ((entered || played) && canPost && !core::Trim(_input).empty()) {
                controller.Submit(std::exchange(_input, std::string()));
            }
        }
    }
    ImGui::End();
}
```

```cpp
#include "app/ui/Windows.h"

#include <string>
#include <vector>

#include <imgui.h>
#include <nlohmann/json.hpp>

#include "app/model/Inspect.h"

namespace morpheus::app {

void StateWindow::Draw(AppController& controller)
{
    if (ImGui::Begin(STATE_WINDOW)) {
        const RunModel& run = controller.Run();
        if (!run.Open()) {
            ImGui::TextDisabled("No run open.");
        } else {
            // Marks come from the latest committed turn's applied changes.
            const core::TurnRecord* pLatest = run.LatestTurn();
            const std::vector<core::AppliedChange> noChanges;
            const std::vector<core::AppliedChange>& applied = pLatest ? pLatest->applied : noChanges;
            if (pLatest) {
                ImGui::TextDisabled("After turn %d. Highlighted: what it changed.", pLatest->number);
            } else {
                ImGui::TextDisabled("The world's initial state.");
            }

            // Pushes the text color for a mark. Returns whether it pushed one, which the caller then pops.
            auto pushMark = [](ChangeMark mark) {
                if (mark == ChangeMark::None) {
                    return false;
                }
                ImGui::PushStyleColor(ImGuiCol_Text, mark == ChangeMark::Changed ? CHANGED_COLOR : CONTAINS_COLOR);
                return true;
            };
            // A leaf line in the color of the node at `path`.
            auto leaf = [&](const std::string& path, const std::string& text) {
                const bool pushed = pushMark(MarkFor(path, applied));
                ImGui::BulletText("%s", text.c_str());
                if (pushed) {
                    ImGui::PopStyleColor();
                }
            };
            // A value as the tree shows it: strings without quotes, anything else as JSON.
            auto valueText = [](const nlohmann::json& value) {
                return value.is_string() ? value.get<std::string>() : value.dump();
            };

            // Entities, then their fields. Counters and lists open one more level.
            for (const auto& [id, entity] : run.State().items()) {
                const bool entityPushed = pushMark(MarkFor(id, applied));
                const bool entityOpen = ImGui::TreeNodeEx(id.c_str(), ImGuiTreeNodeFlags_DefaultOpen, "%s (%s)",
                                                          id.c_str(), entity.at("type").get<std::string>().c_str());
                if (entityPushed) {
                    ImGui::PopStyleColor();
                }
                if (!entityOpen) {
                    continue;
                }
                for (const auto& [field, value] : entity.at("fields").items()) {
                    const std::string path = id + "." + field;
                    if (!value.is_object() && !value.is_array()) {
                        leaf(path, field + ": " + valueText(value));
                        continue;
                    }
                    const bool fieldPushed = pushMark(MarkFor(path, applied));
                    const bool fieldOpen = ImGui::TreeNodeEx(path.c_str(), ImGuiTreeNodeFlags_DefaultOpen, "%s (%zu)",
                                                             field.c_str(), value.size());
                    if (fieldPushed) {
                        ImGui::PopStyleColor();
                    }
                    if (!fieldOpen) {
                        continue;
                    }
                    if (value.is_object()) {
                        // A counter: each item has its own path.
                        for (const auto& [item, count] : value.items()) {
                            leaf(path + "." + item, item + ": " + count.dump());
                        }
                    } else {
                        // A list: its elements change with the field.
                        for (const nlohmann::json& element : value) {
                            leaf(path, valueText(element));
                        }
                    }
                    ImGui::TreePop();
                }
                ImGui::TreePop();
            }
        }
    }
    ImGui::End();
}
```

```cpp
#include "app/ui/Windows.h"

#include <cfloat>
#include <cstddef>
#include <format>

namespace morpheus::app {

namespace {

constexpr std::size_t TITLE_INPUT_CHARS = 60;    // The input shown in a turn's header, in bytes.
constexpr float RESOLVE_JSON_LINES = 12.0f;      // Height of the raw resolve output, in lines.
constexpr const char* CALLS[] = {"lookup", "resolve", "narrate"}; // Model calls, in turn order.

} // namespace

void TurnLogWindow::Draw(AppController& controller)
{
    if (ImGui::Begin(TURN_LOG_WINDOW)) {
        const std::vector<core::TurnRecord>& history = controller.Run().History();
        if (history.empty()) {
            ImGui::TextDisabled("No turns yet.");
        }
        // Newest first; the latest starts open.
        for (auto it = history.rbegin(); it != history.rend(); ++it) {
            const core::TurnRecord& turn = *it;
            ImGui::PushID(turn.number);
            if (it == history.rbegin()) {
                ImGui::SetNextItemOpen(true, ImGuiCond_Once);
            }
            // "###header" keeps the header's ID stable while its label changes (a regenerate adds an attempt).
            const std::string attempt = turn.attempt > 0 ? std::format(" (attempt {})", turn.attempt + 1) : std::string();
            const std::string title = std::format("Turn {}{}: {}###header", turn.number, attempt,
                                                  core::CutUtf8(turn.input, TITLE_INPUT_CHARS));
            if (ImGui::CollapsingHeader(title.c_str())) {
                // What the player asked and what the model made of it.
                ImGui::TextWrapped("Input: %s", turn.input.c_str());
                const nlohmann::json intent =
                    turn.resolve.is_object() ? turn.resolve.value("intent", nlohmann::json()) : nlohmann::json();
                ImGui::TextWrapped("Intent: %s", intent.is_string() ? intent.get<std::string>().c_str() : "(none)");

                if (!turn.checks.empty()) {
                    ImGui::SeparatorText("Checks");
                    for (const core::CheckOutcome& check : turn.checks) {
                        ImGui::Bullet();
                        ImGui::TextWrapped("%s (stakes: %s)", CheckText(check).c_str(), check.stakes.c_str());
                    }
                }
                if (!turn.applied.empty()) {
                    ImGui::SeparatorText("Applied");
                    for (const core::AppliedChange& applied : turn.applied) {
                        ImGui::Bullet();
                        ImGui::TextWrapped("%s - %s", context::RenderChangePart(applied).c_str(),
                                           applied.change.reason.c_str());
                    }
                }
                if (!turn.rejected.empty()) {
                    ImGui::SeparatorText("Rejected");
                    for (const core::RejectedChange& rejected : turn.rejected) {
                        TextWrappedColored(ERROR_COLOR, std::format("{} - {}", rejected.raw.dump(), rejected.reason));
                    }
                }
                if (!turn.notes.empty()) {
                    ImGui::SeparatorText("Notes");
                    for (const std::string& note : turn.notes) {
                        ImGui::Bullet();
                        ImGui::TextWrapped("%s", note.c_str());
                    }
                }

                // Assisted mode: what the lookup call asked for, and how much of it reached the prompt.
                const nlohmann::json& timings = turn.timings;
                if (timings.is_object() && timings.contains("lookup")) {
                    ImGui::SeparatorText("Lookups");
                    const nlohmann::json& lookup = timings.at("lookup");
                    for (const nlohmann::json& request : lookup.value("requests", nlohmann::json::array())) {
                        ImGui::Bullet();
                        ImGui::TextWrapped("%s \"%s\": %zu found, %zu reached the prompt",
                                           request.at("source").get<std::string>().c_str(),
                                           request.at("query").get<std::string>().c_str(), request.at("added").size(),
                                           request.value("kept", nlohmann::json::array()).size());
                    }
                    if (lookup.contains("error")) {
                        TextWrappedColored(ERROR_COLOR,
                                           "Unreadable lookup output: " + lookup.at("error").get<std::string>());
                    }
                }

                // Each model call's numbers.
                ImGui::SeparatorText("Calls");
                if (ImGui::BeginTable("calls", 6,
                                      ImGuiTableFlags_Borders | ImGuiTableFlags_RowBg | ImGuiTableFlags_SizingFixedFit)) {
                    for (const char* header : {"Call", "Prompt", "Reused", "Generated", "Prompt ms", "Generate ms"}) {
                        ImGui::TableSetupColumn(header);
                    }
                    ImGui::TableHeadersRow();
                    for (const char* call : CALLS) {
                        const std::optional<CallStats> stats = CallStatsOf(timings, call);
                        if (!stats) {
                            continue;
                        }
                        ImGui::TableNextRow();
                        ImGui::TableNextColumn();
                        ImGui::TextUnformatted(call);
                        if (stats->stoppedAtLimit) {
                            ImGui::SameLine();
                            ImGui::TextColored(WARNING_COLOR, "(hit max tokens)");
                        }
                        ImGui::TableNextColumn();
                        ImGui::Text("%d", stats->promptTokens);
                        ImGui::TableNextColumn();
                        ImGui::Text("%d", stats->reused);
                        ImGui::TableNextColumn();
                        ImGui::Text("%d", stats->generated);
                        ImGui::TableNextColumn();
                        ImGui::Text("%.0f", stats->promptMs);
                        ImGui::TableNextColumn();
                        ImGui::Text("%.0f", stats->generateMs);
                    }
                    ImGui::EndTable();
                }
                if (timings.is_object() && timings.contains("resolve") && timings.at("resolve").contains("error")) {
                    TextWrappedColored(ERROR_COLOR, "Unreadable resolve output: " +
                                                        timings.at("resolve").at("error").get<std::string>());
                }

                // The resolve output exactly as the model wrote it.
                if (ImGui::TreeNode("Resolve output (JSON)")) {
                    std::string json = turn.resolve.dump(2);
                    ImGui::InputTextMultiline("##resolve", &json,
                                              ImVec2(-FLT_MIN, ImGui::GetTextLineHeight() * RESOLVE_JSON_LINES),
                                              ImGuiInputTextFlags_ReadOnly);
                    ImGui::TreePop();
                }
            }
            ImGui::PopID();
        }
    }
    ImGui::End();
}
```

```cpp
                                                                                        : core::MemoryMode::Assisted);
            }

            // The budget is shown, not edited here: it is tuned in settings.json.
            ImGui::SeparatorText("Budget (edit settings.json)");

                _problem.clear();

        }
```

```cpp
// morpheus: the app. An SDL3 window with Dear ImGui docking windows over the engine worker (architecture spec, "UI").
//
// Usage: morpheus [root] [--frames N]
// root holds settings.json, game_projects/ and saves/ (default: the current directory); Visual Studio starts the app
// from the repository root. --frames N exits after N frames: a smoke check that the window, the font, the ImGui
// backends and the settings start on this machine.

#include <charconv>
#include <exception>
#include <filesystem>
#include <iostream>
#include <memory>
#include <optional>
#include <stdexcept>
#include <string>
#include <string_view>
#include <system_error>

#include <SDL3/SDL.h>
#include <imgui.h>
#include <imgui_impl_sdl3.h>
#include <imgui_impl_sdlrenderer3.h>

#include "app/model/AppController.h"
#include "app/ui/Ui.h"
#include "core/Text.h"
#include "llama/LlamaCppBackend.h"

using namespace morpheus;

namespace {

constexpr const char* WINDOW_TITLE = "Morpheus Engine";
constexpr int WINDOW_WIDTH = 1600; // Before display scaling.
constexpr int WINDOW_HEIGHT = 900;
constexpr float FONT_SIZE = 18.0f; // Before display scaling.
constexpr const char* USAGE = "usage: morpheus [root] [--frames N]\n";

struct WindowDeleter {
    void operator()(SDL_Window* pWindow) const
    {
        SDL_DestroyWindow(pWindow);
    }
};
struct RendererDeleter {
    void operator()(SDL_Renderer* pRenderer) const
    {
        SDL_DestroyRenderer(pRenderer);
    }
};
struct ImGuiContextDeleter {
    void operator()(ImGuiContext* pContext) const
    {
        ImGui::DestroyContext(pContext);
    }
};

// SDL's video subsystem: started by the constructor, shut down by the destructor.
class SdlSession {
public:
    SdlSession()
    {
        if (!SDL_Init(SDL_INIT_VIDEO)) {
            throw std::runtime_error(std::string("SDL_Init failed: ") + SDL_GetError());
        }
    }
    ~SdlSession()
    {
        SDL_Quit();
    }
    SdlSession(const SdlSession&) = delete;
    SdlSession& operator=(const SdlSession&) = delete;
};

// ImGui's SDL3 platform backend and SDL_Renderer backend, shut down in reverse order.
class ImGuiBackends {
public:
    ImGuiBackends(SDL_Window* pWindow, SDL_Renderer* pRenderer)
    {
        if (!ImGui_ImplSDL3_InitForSDLRenderer(pWindow, pRenderer)) {
            throw std::runtime_error("the ImGui SDL3 backend failed to start");
        }
        if (!ImGui_ImplSDLRenderer3_Init(pRenderer)) {
            ImGui_ImplSDL3_Shutdown();
            throw std::runtime_error("the ImGui SDL_Renderer backend failed to start");
        }
    }
    ~ImGuiBackends()
    {
        ImGui_ImplSDLRenderer3_Shutdown();
        ImGui_ImplSDL3_Shutdown();
    }
    ImGuiBackends(const ImGuiBackends&) = delete;
    ImGuiBackends& operator=(const ImGuiBackends&) = delete;
};

// The llama.cpp backend for the engine's settings. Runs on EngineHost's loader thread.
std::unique_ptr<inference::LlmBackend> MakeLlamaBackend(const core::Settings& settings)
{
    llama::LlamaConfig config;
    config.chatModel = settings.chatModel;
    config.embeddingModel = settings.embeddingModel;
    config.embeddingQueryPrefix = settings.embeddingQueryPrefix;
    config.embeddingDocumentPrefix = settings.embeddingDocumentPrefix;
    config.contextSize = settings.contextSize;
    config.gpuLayers = settings.gpuLayers;
    return std::make_unique<llama::LlamaCppBackend>(config);
}

} // namespace

int main(int argc, char** argv)
{
    // Arguments: an optional root folder, and --frames N.
    std::optional<std::filesystem::path> rootArgument;
    std::optional<long long> frameLimit;
    for (int i = 1; i < argc; ++i) {
        const std::string_view argument = argv[i];
        if (argument == "--frames" && i + 1 < argc) {
            const std::string_view text = argv[++i];
            long long frames = 0;
            const auto [pNext, error] = std::from_chars(text.data(), text.data() + text.size(), frames);
            if (error != std::errc() || pNext != text.data() + text.size() || frames < 1) {
                std::cerr << USAGE;
                return 2;
            }
            frameLimit = frames;
        } else if (!rootArgument && !argument.starts_with("--")) {
            rootArgument = std::filesystem::path(std::string(argument));
        } else {
            std::cerr << USAGE;
            return 2;
        }
    }

    try {
        const std::filesystem::path root = rootArgument.value_or(std::filesystem::current_path());

        // The window and its renderer, sized for the display's scale.
        const SdlSession sdl;
        const float scale = SDL_GetDisplayContentScale(SDL_GetPrimaryDisplay());
        if (scale <= 0.0f) {
            throw std::runtime_error(std::string("SDL_GetDisplayContentScale failed: ") + SDL_GetError());
        }
        const std::unique_ptr<SDL_Window, WindowDeleter> pWindow(
            SDL_CreateWindow(WINDOW_TITLE, static_cast<int>(WINDOW_WIDTH * scale), static_cast<int>(WINDOW_HEIGHT * scale),
                             SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY));
        if (!pWindow) {
            throw std::runtime_error(std::string("SDL_CreateWindow failed: ") + SDL_GetError());
        }
        const std::unique_ptr<SDL_Renderer, RendererDeleter> pRenderer(SDL_CreateRenderer(pWindow.get(), nullptr));
        if (!pRenderer) {
            throw std::runtime_error(std::string("SDL_CreateRenderer failed: ") + SDL_GetError());
        }
        SDL_SetRenderVSync(pRenderer.get(), 1); // Caps the frame rate at the display's.

        // ImGui. The layout is saved beside settings.json. ImGui keeps the file name's pointer until the context is
        // destroyed, so the string is declared first and outlives it.
        const std::string iniFile = core::PathText(root / "imgui.ini");
        IMGUI_CHECKVERSION();
        const std::unique_ptr<ImGuiContext, ImGuiContextDeleter> pImGui(ImGui::CreateContext());
        ImGuiIO& io = ImGui::GetIO();
        io.ConfigFlags |= ImGuiConfigFlags_DockingEnable | ImGuiConfigFlags_NavEnableKeyboard;
        io.IniFilename = iniFile.c_str();
        ImGui::StyleColorsDark();
        ImGuiStyle& style = ImGui::GetStyle();
        style.ScaleAllSizes(scale);
        style.FontScaleDpi = scale;

        // Segoe UI covers the punctuation narration uses (dashes, curly quotes), which ImGui's built-in font lacks.
        const char* pWindowsDir = SDL_getenv("WINDIR");
        if (!pWindowsDir) {
            throw std::runtime_error("WINDIR is not set, so the Windows fonts folder cannot be found");
        }
        const std::filesystem::path fontFile = std::filesystem::path(pWindowsDir) / "Fonts" / "segoeui.ttf";
        if (!std::filesystem::exists(fontFile)) {
            throw std::runtime_error("font file " + core::PathText(fontFile) + " does not exist");
        }
        io.Fonts->AddFontFromFileTTF(core::PathText(fontFile).c_str(), FONT_SIZE);

        const ImGuiBackends backends(pWindow.get(), pRenderer.get());

        // The app: settings, worlds and the engine (its models load in the background while the UI draws).
        app::AppController controller(app::AppController::PathsUnder(root), MakeLlamaBackend);
        app::Ui ui;

        bool running = true;
        for (long long frame = 0; running && (!frameLimit || frame < *frameLimit); ++frame) {
            SDL_Event event;
            while (SDL_PollEvent(&event)) {
                ImGui_ImplSDL3_ProcessEvent(&event);
                if (event.type == SDL_EVENT_QUIT || (event.type == SDL_EVENT_WINDOW_CLOSE_REQUESTED &&
                                                     event.window.windowID == SDL_GetWindowID(pWindow.get()))) {
                    running = false;
                }
            }
            controller.Frame(); // Take the worker's events even while minimized.
            if ((SDL_GetWindowFlags(pWindow.get()) & SDL_WINDOW_MINIMIZED) != 0) {
                SDL_Delay(10); // Nothing to draw.
                continue;
            }

            ImGui_ImplSDLRenderer3_NewFrame();
            ImGui_ImplSDL3_NewFrame();
            ImGui::NewFrame();
            ui.Draw(controller);
            ImGui::Render();
            SDL_SetRenderScale(pRenderer.get(), io.DisplayFramebufferScale.x, io.DisplayFramebufferScale.y);
            SDL_SetRenderDrawColorFloat(pRenderer.get(), 0.08f, 0.08f, 0.08f, 1.0f);
            SDL_RenderClear(pRenderer.get());
            ImGui_ImplSDLRenderer3_RenderDrawData(ImGui::GetDrawData(), pRenderer.get());
            SDL_RenderPresent(pRenderer.get());
        }
        return 0; // Members unwind in reverse: the worker stops, then ImGui (saving the layout), then SDL.
    } catch (const std::exception& error) {
        // Startup failures (invalid settings.json, a missing font) and UI bugs end here, shown rather than swallowed.
        std::cerr << "error: " << error.what() << '\n';
        if (!frameLimit) {
            SDL_ShowSimpleMessageBox(SDL_MESSAGEBOX_ERROR, WINDOW_TITLE, error.what(), nullptr);
        }
        return 1;
    }
}
```
