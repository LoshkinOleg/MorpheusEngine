# Rolling a hosted run back (sub-project E2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When the player loads a save, the host tells Morpheus the save's game time and the run looks as it did then: later records are hidden, not deleted, NPCs neither show nor remember them, a later rewind restores them exactly until something new is played, and playing on abandons them.

**Architecture:** The host data names a clock (a JSON pointer to a number in the observation); every hosted record stores its clock. Rollbacks are materialized: a rollback row saves the fold marks, every row it hides carries `hidden_by`, readers skip hidden rows, an undo reverses it, and the first new record abandons it. `HostedSession::Rewind(gameTime)` (one idempotent call per save load) undoes the open rollback and applies a new one when the time is before the latest live clock; `morpheus_server` exposes it as `POST /v1/runs/{run_id}/rewind` (API 1.2.0).

**Tech Stack:** C++20, CMake, SQLite (`store`), nlohmann::json, cpp-httplib (server), Catch2 v3.

**Spec:** `docs/superpowers/specs/2026-11-16-rollback-design.md`. Read it before Task 1; E1's spec (`2026-11-16-per-speaker-memory-design.md`) describes the memory model this changes.

## Global Constraints

- The clock: `HostData::clock` is an optional JSON pointer (RFC 6901) into the observation; with it, every observation must hold a finite number there (a fault "observation at <pointer>: expected the clock, a number"). Without it, a rewind is a `core::DataError` "game_time: the host data names no clock".
- Record clocks: a turn, a conversation start and a participant change take their observation's clock; an event, a conversation end, a share's copies, a pending share's creation and its application take the run's latest seen clock (the highest clock among visible records; none before the first). A null clock is never hidden.
- A rollback to T hides (`hidden_by` = its id): turns, events, participant changes and conversation ends clocked after T; conversations started after T; shared copies and pending shares created after T; every NPC summary covering a hidden turn (`toTurn` past the last visible turn of its conversation, or past the run's last visible turn for a summary with no conversation). A summary is shown when it is visible and not superseded by a visible summary (`superseded_by`). A pending share applied after T is unapplied by the rollback.
- Marks on a rollback: saved first; then per conversation with last visible turn `cut`: `folded_through` = min(saved, cut); each NPC's mark = min(saved, cut) and at most `fromTurn - 1` of each of its own hidden fold summaries of that conversation (conversation set, not a shared copy, not a condense) that covers a visible turn.
- Undo: show again what the rollback hid, delete summaries `made_in` it (with their embeddings), re-apply unapplied shares, restore the saved marks exactly, status `undone`. Abandon (the first new record while a rollback is open): status `abandoned`, its hidden rows stay hidden for good, `made_in` cleared on its summaries, unapplied shares become pending (`applied` 0, `applied_clock` null), saved marks dropped. Every summary written while a rollback is open carries `made_in` = its id; Maintain never abandons.
- `Rewind(gameTime)`: undo the open rollback, then apply one when `gameTime` is below the latest live clock; a rewind to the open rollback's own time changes nothing. At most one rollback is open.
- Turn numbers stay run-wide unique: the next turn is one past every turn ever stored; "a conversation's latest turn" reads visible turns.
- Store schema version 6 (columns and tables in the spec's section 4). Owned runs gain columns only; Morpheus's own game stays byte-identical (`[turn]`, `[replay]`, `[context]` unchanged, no Session test or replay edited).
- `api_version` becomes `"1.2.0"`. `POST /v1/runs/{run_id}/rewind` with `{game_time}` answers `{rewound, hidden_turns, restored_turns, rollback}` (`rollback`: `{"game_time": T}` of the open rollback after the call, or null).
- CLAUDE.md coding rules apply to every line (fail fast; comments that read top to bottom; a private helper only with more than one caller; class layout; naming; members initialized at declaration; RAII; no legacy paths; ASCII only). Warnings are errors (MSVC `/W4`, Linux `-Wall -Wextra -Wpedantic -Wconversion -Wshadow`).
- Never range-for over a member of a temporary (`for (x : obj.value("k", json::object()).items())` dangles: copy into a local first). Catch2 test names must not start with `/`; Catch2 macros only on the test thread.
- Tests are written first. Fast loop: `cmake --build --preset tests` then `./build/tests/bin/Debug/morpheus_tests.exe "<tag>"`; full: `ctest --preset tests`, and `ctest --preset asan` after `cmake --build --preset asan`.
- Never stage `settings.json`, `models/`, `imgui.ini` or `docs/references/`. Commit messages end with the implementing model's trailer. Byte checks (0 and 0) on every changed file; leave no `morpheus_tests`, `morpheus_server` or `ctest` process running.

- The upgrade chain gains version 5 to 6, in the same transaction as the earlier steps:

```cpp
    // Version 6 (rollback spec, section 4): clocks and hidden marks on hosted rows, conversations as history, and a
    // superseded summary naming its condense. Existing rows get no clock: a rewind never hides them.
    auto upgradeTo6 = [&db, &file] {
        db.Exec(V6_COLUMNS_SQL); // ALTER TABLE ... ADD COLUMN for every new column above.
        db.Exec(V6_TABLES_SQL);  // conversation_changes, its index, rollbacks.
        // Each conversation's participants and end become its first change row.
        db.Exec("INSERT INTO conversation_changes (conversation_id, clock, participants, ended) "
                "SELECT id, NULL, participants, ended FROM conversations ORDER BY position");
        // A superseded summary names its condense: the actor's first condensed summary written after it (a
        // condensed summary has no conversation and no teller).
        Statement superseded = db.Prepare("SELECT id, actor_id FROM summaries WHERE superseded = 1 ORDER BY id");
        std::vector<std::pair<std::int64_t, std::string>> rows;
        while (superseded.Step()) {
            rows.emplace_back(superseded.ColumnInt(0), superseded.ColumnText(1));
        }
        for (const auto& [id, actor] : rows) {
            Statement condense = db.Prepare("SELECT id FROM summaries WHERE actor_id = ?1 AND id > ?2 AND "
```

```cpp
std::optional<Rollback> RunStore::OpenRollback()
{
    RequireHosted("OpenRollback");
    Statement query = _db.Prepare("SELECT id, game_time FROM rollbacks WHERE status = 'open' ORDER BY id");
    std::optional<Rollback> open;

RollbackCounts RunStore::ApplyRollback(double gameTime)
{
    RequireHosted("ApplyRollback");
    MORPHEUS_REQUIRE(!OpenRollback(), "RunStore::ApplyRollback: a rollback is already open");
    RollbackCounts counts;
    _db.Transaction([&] {
        // The marks it moves, saved first: every conversation's folded mark and every NPC's.
        nlohmann::json saved = {{"folded_through", nlohmann::json::object()}, {"remembered", nlohmann::json::array()}};
        Statement folded = _db.Prepare("SELECT id, folded_through FROM conversations");
        while (folded.Step()) {
            saved["folded_through"][folded.ColumnText(0)] = folded.ColumnInt(1);
        }
        Statement remembered = _db.Prepare("SELECT conversation_id, actor_id, remembered_through FROM actor_memory");
        while (remembered.Step()) {
            saved["remembered"].push_back(
                {remembered.ColumnText(0), remembered.ColumnText(1), remembered.ColumnInt(2)});
        }
        _db.Prepare("INSERT INTO rollbacks (game_time, status, saved_marks) VALUES (?1, 'open', ?2)")
            .Bind(1, gameTime)
            .Bind(2, saved.dump())
            .Run();
        Statement inserted = _db.Prepare("SELECT last_insert_rowid()");
        const bool hasRow = inserted.Step();
        MORPHEUS_REQUIRE(hasRow, "ApplyRollback: last_insert_rowid returned no row");
        const std::int64_t id = inserted.ColumnInt(0);

        // Records clocked after the time, and conversations started after it with everything in them.
        Statement hiddenTurns = _db.Prepare("SELECT COUNT(*) FROM hosted_turns WHERE hidden_by = 0 AND clock > ?1");
        hiddenTurns.Bind(1, gameTime);
        hiddenTurns.Step();
        counts.hiddenTurns = static_cast<int>(hiddenTurns.ColumnInt(0));
        for (const char* table : {"hosted_turns", "conversation_events", "conversation_changes", "conversations"}) {
            _db.Prepare(std::format("UPDATE {} SET hidden_by = ?1 WHERE hidden_by = 0 AND clock > ?2", table))
                .Bind(1, id)
                .Bind(2, gameTime)
                .Run();
        }
        // Shared copies and pending shares made after it; shares applied after it are pending again.
        _db.Prepare("UPDATE summaries SET hidden_by = ?1 WHERE hidden_by = 0 AND clock > ?2").Bind(1, id).Bind(2, gameTime).Run();
        _db.Prepare("UPDATE pending_shares SET hidden_by = ?1 WHERE hidden_by = 0 AND clock > ?2")
            .Bind(1, id)
            .Bind(2, gameTime)
            .Run();
        _db.Prepare("UPDATE pending_shares SET unapplied_by = ?1 WHERE hidden_by = 0 AND applied = 1 AND unapplied_by = 0 "
                    "AND applied_clock > ?2")
            .Bind(1, id)
            .Bind(2, gameTime)
            .Run();
        // Summaries covering a hidden turn: past their conversation's last visible turn, or, with no conversation,
        // past the run's.
        _db.Prepare("UPDATE summaries SET hidden_by = ?1 WHERE hidden_by = 0 AND conversation_id <> '' AND to_turn > "
                    "COALESCE((SELECT MAX(number) FROM hosted_turns t WHERE t.conversation_id = summaries.conversation_id "
                    "AND t.hidden_by = 0), 0)")
            .Bind(1, id)
            .Run();
        _db.Prepare("UPDATE summaries SET hidden_by = ?1 WHERE hidden_by = 0 AND conversation_id = '' AND to_turn > "
                    "COALESCE((SELECT MAX(number) FROM hosted_turns WHERE hidden_by = 0), 0)")
            .Bind(1, id)
            .Run();
        // Marks back to each conversation's last visible turn, and an NPC's behind its own hidden fold summaries
        // that cover a visible turn (the catch-up refolds those turns).
        _db.Prepare("UPDATE conversations SET folded_through = MIN(folded_through, COALESCE((SELECT MAX(number) FROM "
                    "hosted_turns t WHERE t.conversation_id = conversations.id AND t.hidden_by = 0), 0))")
            .Run();
        _db.Prepare("UPDATE actor_memory SET remembered_through = MIN(remembered_through, COALESCE((SELECT MAX(number) "
                    "FROM hosted_turns t WHERE t.conversation_id = actor_memory.conversation_id AND t.hidden_by = 0), 0))")
            .Run();
        _db.Prepare("UPDATE actor_memory SET remembered_through = MIN(remembered_through, COALESCE((SELECT "
                    "MIN(s.from_turn) - 1 FROM summaries s WHERE s.hidden_by = ?1 AND s.actor_id = actor_memory.actor_id "
                    "AND s.conversation_id = actor_memory.conversation_id AND s.told_by = '' AND s.from_turn <= "
                    "COALESCE((SELECT MAX(number) FROM hosted_turns t WHERE t.conversation_id = actor_memory.conversation_id "
                    "AND t.hidden_by = 0), 0)), remembered_through))")
            .Bind(1, id)
            .Run();
    });
    return counts;
}

RollbackCounts RunStore::UndoRollback()
{
    RequireHosted("UndoRollback");
    const std::optional<Rollback> open = OpenRollback();
    MORPHEUS_REQUIRE(open.has_value(), "RunStore::UndoRollback: no rollback is open");
    // The saved marks, read before anything changes: damaged ones stop the undo.
    Statement marks = _db.Prepare("SELECT saved_marks FROM rollbacks WHERE id = ?1");
    marks.Bind(1, open->id);
    marks.Step();
    const nlohmann::json saved = nlohmann::json::parse(marks.ColumnText(0), nullptr, false);
    if (saved.is_discarded() || !saved.contains("folded_through") || !saved.contains("remembered")) {
        throw StoreError(std::format("'{}': rollback {}: saved_marks is damaged", core::PathText(_file), open->id));
    }
    RollbackCounts counts;
    _db.Transaction([&] {
        Statement restored = _db.Prepare("SELECT COUNT(*) FROM hosted_turns WHERE hidden_by = ?1");
        restored.Bind(1, open->id);
        restored.Step();
        counts.restoredTurns = static_cast<int>(restored.ColumnInt(0));
        // Refolds made while it was open go, with their vectors; what it hid comes back.
        _db.Prepare("DELETE FROM embeddings WHERE kind = 'summary' AND CAST(ref_id AS INTEGER) IN (SELECT id FROM "
                    "summaries WHERE made_in = ?1)")
            .Bind(1, open->id)
            .Run();
        _db.Prepare("DELETE FROM summary_supersessions WHERE condensed_id IN (SELECT id FROM summaries WHERE "
                    "made_in = ?1)")
            .Bind(1, open->id)
            .Run();
        _db.Prepare("DELETE FROM summaries WHERE made_in = ?1").Bind(1, open->id).Run();
        for (const char* table : {"hosted_turns", "conversation_events", "conversation_changes", "conversations",
                                  "summaries", "pending_shares"}) {
            _db.Prepare(std::format("UPDATE {} SET hidden_by = 0 WHERE hidden_by = ?1", table)).Bind(1, open->id).Run();
        }
```

```cpp
RewindResult HostedSession::Rewind(double gameTime)
{
    if (!_world.HasClock()) {
        throw core::DataError("game_time: the host data names no clock, so the run cannot be rewound");
    }
    if (!std::isfinite(gameTime)) {
        throw core::DataError("game_time: expected a finite number");
    }
    // The same time as the open rollback: nothing to do.
    const std::optional<store::Rollback> open = _store.OpenRollback();
    if (open && open->gameTime == gameTime) {
        return {false, 0, 0, gameTime};
    }
    // Undo the open rollback, then apply one when the time is before the latest live record.
    RewindResult result;
    if (open) {
        result.restoredTurns = _store.UndoRollback().restoredTurns;
    }
    const std::optional<double> latest = _store.LatestClock();
    if (latest && gameTime < *latest) {
        result.hiddenTurns = _store.ApplyRollback(gameTime).hiddenTurns;
        result.rollbackTime = gameTime;
    }
    // The host sees the net change. Both rollbacks hide every turn clocked after their time, so one of the two sets
    // holds the other: a turn restored by the undo and hidden again by the new rollback counts as neither.
    const int both = std::min(result.restoredTurns, result.hiddenTurns);
    result.restoredTurns -= both;
    result.hiddenTurns -= both;
    // Rewound: the open rollback changed (one was undone, applied, or both; the same time returned early above).
    result.rewound = open.has_value() || result.rollbackTime.has_value();
    SyncHistory();
    return result;
}
```
